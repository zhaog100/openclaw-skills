3. 搜索 "Smart Adaptive Ultra-Fast Image Compressor"
4. 点击 "Subscribe to Test" → 选择 Basic 免费套餐
5. 复制 X-RapidAPI-Key

**APITube News**:
1. 访问 https://apitube.io
2. 点击 "Sign Up" 注册
3. 进入 Dashboard → API Keys
4. 复制 API Key

**Meteoblue**:
1. 访问 https://my.meteoblue.com
2. 注册账户（姓名、邮箱、密码）
3. 进入 API 页面 → Create API Key
4. 复制 Token

**Poof**:
1. 访问 https://poof.bg
2. 点击 "Sign Up" 注册
3. 进入 Dashboard → API Keys
4. 复制 API Key

## 7. 快速部署脚本

### 7.1 一键部署脚本

创建 `deploy-xiaomijiao.sh`:

```bash
#!/bin/bash
# 小米椒环境一键部署脚本
# 使用：bash deploy-xiaomijiao.sh

set -e

echo "🌶️‍🔥 开始部署小米椒环境..."

# 1. 系统依赖
echo "[1/6] 安装系统依赖..."
sudo apt update
sudo apt install -y ffmpeg git

# 2. Python 库
echo "[2/6] 安装 Python 库..."
pip3 install vaderSentiment rake-nltk plotly pandas numpy requests beautifulsoup4 lxml openai-whisper gTTS moviepy sumy qrcode nltk --break-system-packages

# 3. NLTK 数据
echo "[3/6] 下载 NLTK 数据..."
python3 -c "
import nltk
nltk.download('punkt', quiet=True)
nltk.download('punkt_tab', quiet=True)
nltk.download('averaged_perceptron_tagger', quiet=True)
nltk.download('averaged_perceptron_tagger_eng', quiet=True)
nltk.download('stopwords', quiet=True)
"

# 4. 验证安装
echo "[4/6] 验证安装..."
python3 -c "
import vaderSentiment, rake_nltk, plotly, pandas, numpy, requests, bs4, lxml, whisper, gtts, moviepy, sumy, qrcode, nltk
print('✅ Python 库验证通过')
"

ffmpeg -version | head -1
echo "✅ FFmpeg 验证通过"

# 5. Git 配置
echo "[5/6] 配置 Git..."
git config --global user.name "小米椒"
git config --global user.email "xiaomijiao@example.com"

# 6. 克隆仓库
echo "[6/6] 克隆工作仓库..."
# 根据实际情况调整仓库地址
# git clone https://github.com/zhaog100/xiaomijiao-skills.git ~/.openclaw/workspace

echo ""
echo "🎉 部署完成！"
echo ""
echo "下一步操作："
echo "1. 配置云端 API Key（secrets/api-keys.json）"
echo "2. 安装 OpenClaw Skills"
echo "3. 恢复记忆文件和知识库"
echo "4. 启动 Gateway: openclaw gateway start"
echo ""
```

### 7.2 使用方法

```bash
# 下载脚本
curl -O https://raw.githubusercontent.com/zhaog100/xiaomijiao-skills/main/docs/deploy-xiaomijiao.sh

# 赋予执行权限
chmod +x deploy-xiaomijiao.sh

# 执行部署
bash deploy-xiaomijiao.sh
```

## 9. 常见问题

### Q1: pip 安装失败

```bash
# 使用 --break-system-packages 参数
pip3 install <包名> --break-system-packages

# 或使用虚拟环境
python3 -m venv venv
source venv/bin/activate
pip install <包名>
```

### Q2: NLTK 数据下载失败

```bash
# 手动指定下载目录
python3 -c "
import nltk
nltk.download('punkt', download_dir='/root/nltk_data')
"

# 设置 NLTK_DATA 环境变量
export NLTK_DATA=/root/nltk_data
```

### Q3: FFmpeg 无法安装

```bash
# 添加 deadsnakes PPA
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt update
sudo apt install ffmpeg
```

### Q4: API Key 失效

```bash
# 重新注册对应 API
# 见第 4 节 云端 API 注册步骤
```

### Q5: Git 推送失败

```bash
# 检查 remote 配置
git remote -v

# 重新添加 remote
git remote add xiaomijiao https://github.com/zhaog100/xiaomijiao-skills.git

# 强制推送（谨慎使用）
git push xiaomijiao main --force
```
