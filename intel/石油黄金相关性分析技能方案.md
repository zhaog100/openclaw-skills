## 一、功能需求

实时获取黄金（XAU/USD）和原油（WTI/Brent）价格数据，计算两者之间的相关性，输出可视化图表和分析结论。

### 核心功能
1. **实时报价**：黄金、原油当前价格 + 涨跌幅
2. **相关性计算**：Pearson / Spearman 相关系数，支持不同时间窗口（7天/30天/90天/1年）
3. **可视化**：价格走势叠加图、相关性热力图、滚动相关系数图
4. **趋势解读**：用自然语言输出分析结论

## 四、核心算法

### 4.1 数据获取

```python
import yfinance as yf
import pandas as pd

def fetch_data(period="1y"):
    """获取黄金和原油历史数据"""
    data = yf.download(["GC=F", "CL=F"], period=period, interval="1d")
    df = pd.DataFrame({
        "gold": data["Close"]["GC=F"],
        "oil": data["Close"]["CL=F"]
    }).dropna()
    return df
```

### 4.2 相关性计算

```python
from scipy import stats

def calc_correlation(df, window=None):
    """
    计算相关系数
    - window=None: 全局相关性
    - window=N: 滚动窗口相关性（返回时间序列）
    """
    if window is None:
        pearson = df["gold"].corr(df["oil"])
        spearman, _ = stats.spearmanr(df["gold"], df["oil"])
        return {"pearson": pearson, "spearman": spearman}
    else:
        rolling_pearson = df["gold"].rolling(window).corr(df["oil"])
        return rolling_pearson
```

### 4.3 可视化输出

```python
import plotly.graph_objects as go
from plotly.subplots import make_subplots

def plot_analysis(df, rolling_corr=None):
    fig = make_subplots(rows=3, cols=1, 
        subplot_titles=("价格走势", "收益率散点图", "滚动相关系数"),
        vertical_spacing=0.08)

    # 价格走势（双Y轴）
    fig.add_trace(go.Scatter(x=df.index, y=df["gold"], name="黄金"), row=1, col=1)
    fig.add_trace(go.Scatter(x=df.index, y=df["oil"], name="原油"), row=1, col=1)

    # 散点图
    fig.add_trace(go.Scatter(
        x=df["oil"].pct_change(), y=df["gold"].pct_change(),
        mode="markers", name="日收益率"
    ), row=2, col=1)

    # 滚动相关系数
    if rolling_corr is not None:
        fig.add_trace(go.Scatter(
            x=rolling_corr.index, y=rolling_corr, name="30日滚动相关"
        ), row=3, col=1)

    return fig
```

### 4.4 自然语言结论

```python
def generate_report(df, corr_result):
    """生成分析结论"""
    p = corr_result["pearson"]
    
    if abs(p) > 0.7:
        strength = "强"
    elif abs(p) > 0.4:
        strength = "中等"
    else:
        strength = "弱"
    
    direction = "正相关" if p > 0 else "负相关"
    
    return f"""
    📊 石油-黄金相关性分析

    - 样本数：{len(df)} 个交易日
    - Pearson 相关系数：{p:.4f}
    - Spearman 相关系数：{corr_result['spearman']:.4f}
    - 结论：石油与黄金呈现{strength}{direction}关系
    
    💡 解读：{"同涨同跌倾向明显" if p > 0.4 else "走势相对独立" if abs(p) < 0.3 else "存在一定联动性"}
    """
```

## 八、注意事项

1. **yfinance 限速**：频繁调用会被 Yahoo 封 IP，建议缓存数据（5分钟过期）
2. **交易时间**：周末/节假日无数据，需处理空值
3. **货币单位**：黄金 USD/盎司，原油 USD/桶，不在同一量级，分析时用收益率（pct_change）而非绝对价格
4. **MCP 集成**：Alpha Vantage 有官方 MCP Server，小米辣可以考虑直接集成
