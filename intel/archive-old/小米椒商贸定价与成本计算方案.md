**海外定价公式**：
```
海外售价(USD) = (1688进货价(USD) + 国际运费 + 保险费) × (1 + 利润率)
1688进货价(USD) = 1688进货价(CNY) / 汇率
```

### 汇率设定
```
假设汇率：1美元 = 7.2人民币
```

## 📦 跨境定价示例

### 示例1：蒸汽眼罩海外定价

**基础信息**：
- 1688进货价：¥5/个
- 汇率：7.2（1美元=7.2人民币）
- 1688进货价(USD)：$0.69/个

**成本构成**：
1. 产品成本：$0.69/个
2. 国际运费：$1.50/个（小包空运）
3. 保险费：$0.03/个（3%×1.1×$0.69）
4. 平台费用：$0.30/个（假设售价$10，3%）

**总成本**：$0.69 + $1.50 + $0.03 + $0.30 = $2.52/个

**售价计算**：
- 目标利润率：300%
- 利润：$2.52 × 3 = $7.56
- **海外售价**：$2.52 + $7.56 = $10.08/个

**对比闲鱼定价**：
- 闲鱼售价：¥15.9（约$2.21）
- 海外售价：$10.08（约¥72.6）
- **海外溢价**：约4.5倍

**基础信息**：

3. 保险费：$0.15/个（3%×1.1×$3.47）

**总成本**：$3.47 + $3.00 + $0.15 + $1.50 = $8.12/个

**售价计算**：

- **海外售价**：$8.12 + $16.24 = $24.36/个

**对比闲鱼定价**：
- 闲鱼售价：¥59（约$8.19）
- 海外售价：$24.36（约¥175.4）

## 💱 汇率风险管理

### 策略1：固定汇率定价
```
方法：设定汇率固定为7.2
优势：避免汇率波动影响利润
劣势：汇率有利时损失机会
```

### 策略2：动态汇率定价
```
方法：每周根据汇率调整售价
优势：汇率有利时提高利润
劣势：需要频繁调整售价
```

### 策略3：远期外汇保值（Phase 3）
```
方法：使用远期外汇合约锁定汇率
优势：完全规避汇率风险
成本：需要银行费用
建议：年销售额>$50,000后使用
```

**当前建议**：使用策略1（固定汇率定价）
