## 🆘 故障排查

### 问题1: 定时任务没有推送

**可能原因**:
- Gateway cron 配置问题
- 助手通道连接问题

**解决**:
```bash
# 查看 cron 状态
openclaw cron list

# 查看 cron 执行日志
openclaw cron runs --id <job-id> --limit 3
```

### 问题2: 模板文件读取失败

**可能原因**:
- 文件路径错误
- 文件不存在

**解决**:
```bash
# 检查文件是否存在
ls -l /root/.openclaw/workspace/skills/xiaohongshu-ops-skill/examples/commerce/
```

### 问题3: 推送消息没有收到

**可能原因**:
- QQ Bot 配置问题
- 目标QQ号错误

**解决**:
- 检查 QQ Bot 配置
- 确认目标QQ号正确
