# 小红书技能商贸优化方案

**提出**: 小米椒 🌶️‍🔥
**日期**: 2026-04-13
**目标技能**: `xiaohongshu-ops-skill` 商贸模式增强

---

## 📋 当前痛点（基于实际运营需求）

### 运营路径
1688 一件代发 → 小红书种草 → 闲鱼成交

### 痛点清单
| 痛点 | 现状 | 影响 |
|------|------|------|
| 1688供应商选品 | 手动找5家，无法系统化对比 | 效率低、信息分散 |
| 产品图素材管理 | 3家待回复，无统一管理 | 素材零散、难复用 |
| 闲鱼上架 | 手动上架，无模板 | 重复工作、效率低 |
| 跨平台协同 | 小红书引流→闲鱼无自动关联 | 漏单、转化低 |
| 商贸内容模板 | 通用模板不贴合产品场景 | 内容质量不稳定 |
| 私聊话术 | 有话术但无分类管理 | 回复效率低 |

---

## 🔧 优化方案（6大模块）

### 一、1688供应商选品模块

**新增文件**: `references/xhs-1688-selection.md`

**功能**：
1. 批量对比1688供应商（价格/销量/评价）
2. 自动计算利润率（售价 = 进货价×3-5）
3. 生成供应商对比报告
4. 关键词：一件代发、包邮、销量、回头率

**输出格式**：
```
=== 1688供应商对比报告（蒸汽眼罩）===
供应商A: 进货价¥3.2/盒 | 销量5k+ | 回头率85% | 利润空间¥12-18
供应商B: 进货价¥2.8/盒 | 销量2k+ | 回头率78% | 利润空间¥15-20
供应商C: 进货价¥5.0/盒 | 销量8k+ | 回头率92% | 利润空间¥8-15

推荐: 供应商A（平衡性价比与质量）
```

### 二、产品素材管理模块

**新增文件**: `references/xhs-product-assets.md`

**目录结构**:
```
skills/xiaohongshu-ops-skill/
  assets/
    product-01-steam-eye-mask/
      cover-images/      # 封面图
      detail-images/      # 详情图
      real-shot/          # 实拍图
      user-reviews/       # 买家秀
    product-02-neck-massager/
    product-03-herbal-tea/
```

**功能**：
1. 按产品分类管理素材
2. AI自动生成封面图（使用 image_generate）
3. 素材版本管理（v1/v2/v3）
4. 一键打包素材包

**操作流程**：
```
输入: 产品类型 + 素材类型
输出: 对应目录下的素材列表
自动: 生成封面图建议（颜色/字体/文案）
```

### 四、跨平台协同模块

**新增文件**: `references/xhs-cross-platform-sync.md`

**功能**：
1. 小红书笔记与闲鱼商品的自动关联
2. 引流话术库管理
3. 咨询回复话术库
4. 成交记录与数据统计

**引流话术库**：
```
=== 小红书→闲鱼引流话术 ===
类型1: 直接引流
"宝子，链接在小店~\n闲鱼搜\"蒸汽眼罩\"就能找到~\n或者看主页简介，有店铺链接哈~"

类型2: 咨询引导
"亲，有的~\n今天下单明天发货哈~\n包邮，48小时内发货~"

类型3: 下单确认
"亲，收到订单啦~\n今天下单明天发货哈~\n48小时内发货，包邮~"
```

### 六、数据复盘模块

**新增文件**: `references/xhs-commerce-analytics.md`

**功能**：
1. 小红书笔记数据统计（曝光/点赞/收藏/评论）

1. 闲鱼上架模块 — 马上上架3个商品

### P1（重要项）
3. 商贸内容模板 — 生成首篇笔记

## ⚠️ 注意事项

1. 1688选品优先考虑"一件代发包邮"和"销量高"
2. 闲鱼定价公式：进货价×3-5倍
3. 小红书内容避免"极限词"（最/第一/唯一）
4. 跨平台引流话术要自然，避免明显营销
5. 数据复盘每周执行一次，积累运营经验
