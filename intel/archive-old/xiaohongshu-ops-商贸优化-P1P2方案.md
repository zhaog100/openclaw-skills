## 📋 P1优先级（重要项）

### 1. AI封面图生成集成

**文件**: `scripts/ai-cover-generator.py`

**功能**:
1. 读取商贸模板（`examples/commerce/product-promo-template.md`）
2. 调用 `image_generate` 工具生成封面图
3. 自动添加大字标题+副标题+标签
4. 输出到 `assets/product-*/cover-images/`

**技术规格**:
- 模型：RapidAPI Image Compressor（已配置Key）
- 尺寸：9:16 竖版（1080×1920）
- 颜色：暖色调（米白/浅粉）
- 文字：黑色大字+白色描边

**输出示例**:
```python
# 生成的封面图
# 路径: /root/.openclaw/workspace/skills/xiaohongshu-ops-skill/assets/product-01-steam-eye-mask/cover-images/v1.png
# 尺寸: 1080×1920
# 包含: 产品图(60%) + 主标题"20分钟告别眼疲劳" + 副标题"打工人午休神器" + 标签"¥15.9起|包邮"
```

**开发时间**: 30分钟

### 1. 1688供应商选品脚本

**文件**: `scripts/1688-selector.py`

**功能**:
1. 批量搜索1688供应商（关键词：蒸汽眼罩/颈椎按摩仪）
2. 提取关键信息：价格/销量/评价/回头率
3. 自动计算利润率（售价 = 进货价×3-5）
4. 生成供应商对比报告
5. 推荐最优供应商

**输入**:
```python
keyword = "蒸汽眼罩"
products = ["10片装", "20片装", "30片装"]

```

### 2. 产品素材管理脚本

**文件**: `scripts/asset-manager.py`

**功能**:
1. 按产品分类管理素材（`assets/product-*/`）
2. AI自动生成封面图（调用 `ai-cover-generator.py`）
3. 素材版本管理（v1/v2/v3）
4. 一键打包素材包

**目录结构**:
```
skills/xiaohongshu-ops-skill/
  assets/
    product-01-steam-eye-mask/
      cover-images/          # 封面图
        v1.png
        v2.png
      detail-images/          # 详情图
        detail-1.jpg
        detail-2.jpg
      real-shot/              # 实拍图
        real-1.jpg
        real-2.jpg
      user-reviews/           # 买家秀
        review-1.jpg
        review-2.jpg
    product-02-neck-massager/
    product-03-herbal-tea/
```

**操作流程**:
```bash
# 生成封面图
python3 scripts/asset-manager.py --action generate-cover --product steam-eye-mask

# 打包素材
python3 scripts/asset-manager.py --action pack --product steam-eye-mask

# 查看素材
python3 scripts/asset-manager.py --action list --product steam-eye-mask
```

**输出格式**:
```
=== 产品素材（蒸汽眼罩）===
封面图: 2个版本（v1/v2）
详情图: 5个
实拍图: 3个
买家秀: 2个

推荐使用: v2封面图 + detail-1/2详情图
```

**开发时间**: 2小时

## ⚠️ 注意事项

1. **1688选品优先**: 一件代发包邮 + 销量高 + 回头率高
2. **闲鱼定价公式**: 进货价×3-5倍，阶梯定价提升转化率
3. **小红书内容规范**: 避免"最"/"第一"/"唯一"等极限词
4. **跨平台引流话术**: 自然流畅，避免明显营销
5. **数据复盘**: 每周执行一次，积累运营经验
