## ⚠️ 核心原则

> **重要**: 必须用官方命令配置，**不要手动编辑 JSON**！

### 错误方式 ❌
- 手动编辑 `openclaw.json` 加 `apiKey`
- 手动编辑 `auth-profiles.json` 改 `baseUrl`
- Provider 名用 `"bailian"`（Gateway 不认识）

### 正确方式 ✅
- 使用 `openclaw models auth add` 命令
- Provider 名用 `modelstudio`（OpenClaw 内置名）
- Gateway 会自动映射为 `qwen`

---

## 🔧 配置步骤

### 步骤 1: 添加百炼 API Key

```bash
openclaw models auth add
```

按提示操作：
1. 选择 `custom`（自定义 Provider）
2. 输入 Provider 名：`modelstudio`
3. 选择 Profile 名：`default`
4. 粘贴 API Key: `sk-sp-xxxxxxxxxxxxxxxx`

### 步骤 2: 验证配置

```bash
# 检查配置
cat ~/.openclaw/openclaw.json | python3 -c "
import json,sys
d=json.load(sys.stdin)
print('主模型:', d['agents']['defaults']['model']['primary'])
ms=d['models']['providers']['modelstudio']
print('API 类型:', ms.get('api'))
print('baseUrl:', ms.get('baseUrl'))
"

# 测试模型
openclaw models 2>&1 | grep -A2 "Default"
```

**预期输出**:
```
主模型：modelstudio/qwen3.5-plus
API 类型：openai-completions
baseUrl: https://coding.dashscope.aliyuncs.com/v1
```

### 步骤 3: 设置为主模型（可选）

```bash
# 设置百炼为主模型
session_status model=modelstudio/qwen3.5-plus

# 或修改默认配置
openclaw models auth default modelstudio/qwen3.5-plus
```

## 📊 完整配置示例

**`~/.openclaw/openclaw.json`** (自动生成，不要手动编辑):

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "modelstudio/qwen3.5-plus"
      }
    }
  },
  "models": {
    "providers": {
      "modelstudio": {
        "api": "openai-completions",
        "baseUrl": "https://coding.dashscope.aliyuncs.com/v1"
      }
    }
  },
  "auth": {
    "profiles": {
      "modelstudio:default": {
        "provider": "modelstudio",
        "profile": "default"
      }
    }
  }
}
```

## ⚠️ 踩坑记录

| 错误操作 | 结果 | 原因 |
|----------|------|------|
| Provider 名用 `"bailian"` | 404 | Gateway 不认识 |
| 手动编辑 `baseUrl` 加 `/v1` | 404 | Gateway 用 `.origin` 丢掉路径 |
| 只改 `openclaw.json` | 不生效 | `models.json` 会覆盖 |
| 清理 session override | 必要 | 否则锁死 fallback 模型 |

## 📝 经验教训

> **核心教训**: 改模型必须用 `openclaw models auth add` 命令，不要手动编辑 JSON！

1. OpenClaw 内置百炼 provider 名 = `"modelstudio"`（不是 `"bailian"`）
2. Gateway 内部映射：`modelstudio` → `qwen`
3. Coding Plan baseUrl = `coding.dashscope.aliyuncs.com/v1`（内置，不要手动配）
4. 手动编辑 JSON 的 baseUrl 会丢路径（Gateway 用 `new URL().origin`）
