## 💡 使用指南

### 立即可用的工具（无需API Key，本地运行）
1. **VADER情感分析**：`pip install vaderSentiment`
2. **RAKE关键词提取**：`pip install rake-nltk`
3. **Plotly数据可视化**：`pip install plotly`
4. **Pandas数据分析**：`pip install pandas`
5. **NumPy数值计算**：`pip install numpy`
6. **Requests HTTP请求**：`pip install requests`
7. **BeautifulSoup HTML解析**：`pip install beautifulsoup4 lxml`
8. **Whisper语音识别**：`pip install openai-whisper`
9. **gTTS文本转语音**：`pip install gTTS`
10. **MoviePy视频处理**：`pip install moviepy`
11. **FFmpeg视频处理**：`sudo apt install ffmpeg`

### 需要API Key的API
12. **ShotOG**：无需Key，已测试
13. **Poof**：API Key已确认
14. **Image Compressor**：需要RapidAPI Key
15. **APITube News**：需要APITube账户Key
16. **Meteoblue**：需要meteoblue账户Key

## ⚠️ 注意事项

### API使用限制
- **云端API**（需要API Key）：大部分有调用次数限制
- **本地API**（所有16个工具）：无限制，本地运行

### 数据质量
- **云端API**（免费层）：不能保证100%精准
- **本地API**（开源工具）：准确度取决于算法

### 成本控制
- **云端API**：批量调用 + 缓存机制
- **本地API**：无成本，性能优化
