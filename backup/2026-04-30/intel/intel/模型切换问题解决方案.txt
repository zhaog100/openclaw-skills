模型切换问题解决方案
====================
日期：2026-04-16
作者：小米椒 🌶️‍🔥


一、问题描述
============

模型反复从百炼切回智谱，改配置也不生效。


二、根因分析（三层叠加）
========================

L1: 百炼 Coding Plan 套餐需要专用 baseUrl
    coding.dashscope.aliyuncs.com/v1（不是默认地址）
    用错地址 → key 401 → 所有百炼模型 model_not_found

L2: 百炼整个厂商被 rate limit 时，5个百炼模型全部失败
    Fallback 链逐个尝试 → 最终滚到智谱 glm-5

L3: Fallback 成功后 Gateway 自动写入 session override
    modelOverride=zai/glm-5 锁死会话
    改配置文件不生效，必须手动清理 sessions.json

关键：rate limit 是临时的（等几分钟恢复）
     但 Gateway 把它当永久故障处理 → 锁死


三、解决方案（已部署）
======================

第1步：百炼 baseUrl 已修正
    openclaw.json → models.providers.bailian.baseUrl
    = https://coding.dashscope.aliyuncs.com/v1

第2步：百炼 8 个模型已全部配置
    qwen3.5-plus / qwen3-max-2026-01-23 / qwen3-coder-next
    qwen3-coder-plus / glm-5 / glm-4.7 / kimi-k2.5 / MiniMax-M2.5

第3步：LongCat 4 个模型已补回
    LongCat-Flash-Lite / LongCat-Flash-Chat
    LongCat-Flash-Thinking-2601 / LongCat-Flash-Omni-2603
    baseUrl: https://api.longcat.chat/openai

第4步：Fallback 链优化（10个）
    百炼5个 → 智谱4个 → LongCat 1个
    单向链：百炼rate limit → 全挂 → 智谱接管 → LongCat兜底

第5步：模型守护脚本 model-guard.sh
    路径：scripts/model-guard.sh
    功能：
    - 每5分钟清理 sessions.json 里的 override 字段（11种）
    - 每5分钟清理 auth-state.json 里的 cooldown/errorCount
    - 日志写入 logs/model-guard.log
    已加入系统 crontab：*/5 * * * *

第6步：百炼 API Key 已更新
    新 Key 已写入 auth-profiles.json
    验证：curl 测试百炼 API 返回正常


四、当前模型策略
================

默认主力：bailian/qwen3.5-plus（百炼通义千问3.5）
备用1：zai/glm-5.1（智谱）
备用2：longcat/LongCat-Flash-Lite（美团龙猫，免费）

Fallback 完整链（按顺序）：
 1. bailian/qwen3-max-2026-01-23
 2. bailian/qwen3-coder-next
 3. bailian/glm-5
 4. bailian/glm-4.7
 5. bailian/MiniMax-M2.5
 6. zai/glm-5.1
 7. zai/glm-5
 8. zai/glm-4.7
 9. zai/glm-4.7-flash
10. longcat/LongCat-Flash-Lite


五、防复发机制
==============

model-guard.sh 每5分钟自动：
  - 清理 session override（防止锁死）
  - 清理 auth-state cooldown（防止记住旧故障）
  - 即使被 rate limit 切走，最多5分钟自动切回百炼


六、为什么 Fallback 是单向的
=============================

Fallback 链是单向的：百炼 → 智谱 → LongCat

百炼挂了 → 试百炼其他模型（全挂）→ 智谱 → 锁定智谱
智谱挂了 → 试智谱其他模型 → LongCat → 锁定LongCat
不会回头试百炼

model-guard 的作用：每5分钟重置，让请求重新从百炼开始


七、改动的文件
===============

修改：
  - openclaw.json（百炼baseUrl + LongCat配置 + fallback链）
  - crontab（新增 model-guard 定时任务）

新增：
  - scripts/model-guard.sh（模型守护脚本）

备份：
  - backup/2026-04-16/openclaw.json.bak.20260416_1428


八、注意事项
=============

1. 改模型不只是改配置文件，必须同时清理：
   session override + cron model + auth-state cooldown

2. 百炼 Coding Plan 的 baseUrl 是
   coding.dashscope.aliyuncs.com 不是默认地址

3. Fallback 链不要放没有 auth 的 provider
   会拖慢 fallback 速度

4. model-guard.sh 每5分钟运行，日志在 logs/model-guard.log
   日志不会自动清理，建议每月检查一次
