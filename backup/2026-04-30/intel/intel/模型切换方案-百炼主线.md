# 模型切换方案：主力模型改为百炼

**日期**：2026-04-16
**维护**：小米椒 🌶️‍🔥
**版本**：v1.0

---

## 🔍 问题回顾

模型反复切回智谱 glm-5，已发生 4+ 次。根因不是单一问题，而是**三层叠加**：

| 层 | 问题 | 影响 |
|---|---|---|
| **L1** | 百炼 baseUrl 用了默认地址，Coding Plan 套餐需要专用地址 | 百炼全部 401 → 所有 bailian 模型 model_not_found |
| **L2** | Fallback 链含大量不可用模型（bailian 全挂 + longcat 无 auth） | Fallback 链逐个失败，最终滚到 zai/glm-5 |
| **L3** | Fallback 成功后 Gateway 自动写入 session override | modelOverride=zai/glm-5 锁死会话，改配置文件不生效 |

---

## ✅ 解决方案（已执行）

### 第1步：修正百炼 BaseUrl

```json
// openclaw.json → models.providers.bailian
{
  "baseUrl": "https://coding.dashscope.aliyuncs.com/v1",
  "models": [
    {"id": "qwen3.5-plus", "name": "通义千问3.5-Plus"},
    {"id": "qwen3-max-2026-01-23", "name": "通义千问3-Max"},
    {"id": "qwen3-coder-next", "name": "通义千问3-Coder Next"},
    {"id": "qwen3-coder-plus", "name": "通义千问3-Coder Plus"},
    {"id": "glm-5", "name": "智谱GLM-5"},
    {"id": "glm-4.7", "name": "智谱GLM-4.7"},
    {"id": "kimi-k2.5", "name": "Kimi K2.5"},
    {"id": "MiniMax-M2.5", "name": "MiniMax M2.5"}
  ]
}
```

**关键**：百炼 Coding Plan 套餐必须用 `coding.dashscope.aliyuncs.com`，不是默认的 `dashscope.aliyuncs.com`。否则 key 401。

### 第2步：清理 Fallback 链

```json
// openclaw.json → agents.defaults.model
{
  "primary": "bailian/qwen3.5-plus",
  "fallbacks": [
    "bailian/qwen3-max-2026-01-23",
    "bailian/qwen3-coder-next",
    "bailian/glm-5",
    "bailian/glm-4.7",
    "bailian/MiniMax-M2.5",
    "zai/glm-5",
    "zai/glm-5.1",
    "zai/glm-4.7",
    "zai/glm-4.7-flash",
    "minimax/MiniMax-M2.5"
  ]
}
```

**原则**：Fallback 只放**确认 key 有效**的 provider，不放无 auth 或 key 失效的。

### 第3步：清理 Session Override

```python
# sessions.json 里所有 session 的这些字段必须删除：
# - modelOverride
# - providerOverride
# - authProfileOverride
# - liveModelSwitchPending
```

**为什么**：Gateway fallback 成功后自动写入 override，之后会话锁定在该模型，改配置文件不生效。

### 第4步：清理 Auth-State Cooldown

```python
# auth-state.json → usageStats 里的 cooldown/disabled 字段要清理
# 否则 Gateway 记住"百炼之前失败过"，不会立即重试
```

### 第5步：同步 Cron 任务

```python
# 全部 13 个 cron 任务的 payload.model 统一设为 "bailian/qwen3.5-plus"
# isolated session 不继承 agent 默认模型，必须显式指定
```

### 第6步：热切换 + 验证

```bash
# 当前会话热切换
session_status(model="bailian/qwen3.5-plus")

# 验证百炼 API 可用
curl https://coding.dashscope.aliyuncs.com/v1/chat/completions \
  -H "Authorization: Bearer $KEY" \
  -d '{"model":"qwen3.5-plus","messages":[{"role":"user","content":"hi"}]}'
```

---

## ⚠️ 注意事项

1. **改模型不只是改配置文件**，必须同时清理 session override + cron model + auth-state cooldown
2. **百炼 Coding Plan** 的 baseUrl 是 `coding.dashscope.aliyuncs.com`，不是默认地址
3. **Fallback 链**不要放没有 auth 的 provider（如 longcat），会拖慢 fallback 速度
4. **Gateway 重启**后可能从 JSONL 恢复旧模型，需要确认 session override 已清理
