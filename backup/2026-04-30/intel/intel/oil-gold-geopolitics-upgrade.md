## 📋 需求背景

当前 `advisor.py` 只有纯技术指标分析（RSI/MACD/KDJ/布林带），缺少国际地缘政治和宏观经济形势判断。大宗商品价格受国际事件驱动明显（如4/8中美关税升级导致原油暴跌12.7%），缺少这一层分析会导致建议脱离实际。

---

## 🔧 升级方案

### 新增文件：`scripts/geopolitics.py`

**功能**：自动采集国际财经新闻，筛选与黄金原油相关的地缘事件，生成形势判断文本。

**输入**：无（自动采集）
**输出**：dict，包含 `factors`（关键因素列表）+ `summary`（形势总结）+ `outlook`（对黄金/原油的影响方向）

**核心逻辑**：

```
1. 数据采集（按优先级）
   ├── 百度热搜（已有 hotspot-collector.sh 采集到 intel/热点选题.md）
   ├── akshare 新闻接口（news_cctv / news_economic_baidu）
   └── 备用：读取 intel/热点选题.md 中已采集的热点

2. 关键词过滤
   黄金相关：美联储、降息、加息、美元指数、避险、通胀、CPI
   原油相关：OPEC、减产、增产、伊朗、制裁、关税、贸易战
   共用：中东、俄乌、地缘、冲突、战争、制裁、衰退

3. 影响分析
   对每个匹配事件判断：
   - 利好/利空/中性
   - 影响品种（黄金/原油/两者）
   - 影响程度（强/中/弱）
   - 时效性（短期/中期/长期）

4. 输出格式
   {
     "factors": [
       {"event": "中美关税升级", "impact": "利空原油", "level": "强", "duration": "中期"},
       {"event": "伊朗核谈判接近达成", "impact": "利空原油", "level": "中", "duration": "短期"}
     ],
     "summary": "中美贸易摩擦升级冲击原油需求预期，避险情绪支撑黄金...",
     "gold_outlook": "偏多（避险支撑）",
     "oil_outlook": "偏空（需求担忧+产能释放预期）"
   }
```

### 修改文件：`scripts/advisor.py`

在现有技术分析之后，调用 `geopolitics.py` 获取形势判断，合并到最终报告：

```
现有流程：
  技术指标(RSI/MACD/KDJ/布林带) → 综合评分 → 建议

升级后流程：
  技术指标 → 国际形势分析 → 综合评分（权重调整）→ 建议

```

**报告新增 `🌍 国际形势` 段落**，位于技术指标和综合建议之间。

## ⚠️ 注意事项

1. 新闻采集可能因网络/接口变动失败，需做好降级处理（返回"暂无重大事件"）
2. 形势分析仅为信息整合，不做主观预测，措辞用"利空/利多预期"而非"会跌/会涨"
3. 与现有技术指标独立运行，互不影响（geopolitics 失败不阻塞技术分析）
4. 定时推送（cron 09:05）会自动包含国际形势分析，无需额外配置
