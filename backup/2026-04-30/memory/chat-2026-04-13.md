输入：无（自动采集）

核心逻辑：
  1. 数据采集（按优先级）
     - 百度热搜（已有 hotspot-collector.sh 采集到 intel/热点选题.md）

  2. 关键词过滤
     黄金相关：美联储、降息、加息、美元指数、避险、通胀、CPI
     原油相关：OPEC、减产、增产、伊朗、制裁、关税、贸易战
     共用：中东、俄乌、地缘、冲突、战争、制裁、衰退

  3. 影响分析
     对每个匹配事件判断：
     - 利好/利空/中性
     - 影响品种（黄金/原油/两者）
     - 影响程度（强/中/弱）
     - 时效性（短期/中期/长期）

  4. 输出格式
     {

## 🖥️ 混合架构方案

```
┌─────────────────────┐         ┌─────────────────────┐
│  Windows 电脑        │         │  Linux 服务器         │
│                     │         │                     │
│  淘宝桌面客户端 ✅    │  ←───→  │  OpenClaw Gateway ✅  │
│  taobao-native CLI  │  连接    │  小红书/闲鱼/热点 ✅   │
│  OpenClaw Agent ✅   │         │  定时任务/记忆 ✅      │
│                     │         │                     │
└─────────────────────┘         └─────────────────────┘
```

**原理**：
- Windows 上装淘宝桌面客户端 + OpenClaw Agent
- Linux 上跑 OpenClaw Gateway（现有的）
- Windows Agent 通过 WebSocket 连接到 Linux Gateway
- 淘宝操作走 Windows 本地 CLI，其他任务走 Linux

---

2. **安装 OpenClaw**
   ```powershell
   npm install -g openclaw
   ```

3. **配置连接到 Linux Gateway**
   ```bash
   openclaw config set gateway.remote.url ws://Linux服务器IP:18789
   ```

4. **启动 Agent**
   ```bash
   openclaw agent start
   ```

**优势**：
- ✅ Linux 上的定时任务/记忆/小红书/闲鱼 全部正常
