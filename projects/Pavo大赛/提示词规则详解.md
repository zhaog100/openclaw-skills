## 🎯 核心原则

### 1. 结构清晰
```
[风格前缀] + [主体描述] + [动作/动态] + [环境背景] + [镜头语言] + [光影氛围]
```

### 2. 关键词权重
AI会按顺序理解关键词，**越靠前越重要**：
- 第1-3词：决定整体风格和主体
- 中间部分：描述细节和动态
- 最后部分：渲染氛围和镜头

### 3. 长度控制
- ✅ 推荐：30-80词
- ⚠️ 允许：80-120词
- ❌ 避免：超过150词（会稀释关键信息）

## 🔧 迭代优化技巧

### 第一次生成
使用标准公式，确保基本元素正确

### 第二次调整
- 如果风格不对：调整风格词顺序或替换
- 如果主体不清：增加细节描述
- 如果动作僵硬：添加动态关键词

### 第三次优化
- 添加更多氛围词
- 调整镜头语言
- 优化光影效果

## 📊 常见错误与修正

| 问题 | 原因 | 修正方法 |
|------|------|----------|
| 风格不对 | 风格词不明显 | 把风格词放第一位 |
| 主体不清 | 描述太简单 | 增加外貌细节 |
| 动作不自然 | 缺少动态词 | 添加"moving"、"dynamic" |
| 画面太乱 | 元素过多 | 精简到5-8个关键词 |
| 没有氛围 | 缺少氛围词 | 添加"atmospheric"、"mood" |

## 📝 注意事项

1. **英文优先**：大部分AI模型对英文理解更好
2. **逗号分隔**：用逗号分隔不同要素
3. **避免中文**：除非模型明确支持
4. **测试迭代**：首先生成测试片段，确认效果后再批量生成
5. **保持连贯**：同一作品的提示词风格要统一
