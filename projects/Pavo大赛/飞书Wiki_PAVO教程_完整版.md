# 一、画布模式

## 1. 新建项目 → 进入画布

右击上传资产（人设、场景、道具）、添加节点

## 2. 创建或导入素材

**直接生成**：在画布中输入文本提示词，生成图片或视频。

**导入已有资产**：从资产库导入人物、场景、道具等已有素材，继续使用。

把人物、场景、参考图、视频等内容放在画布上，根据项目关系进行排列

## 3. 在画布中整理创作元素，选择参考素材 → 发起生成

**人物 → 场景 → 分镜 → 视频**

根据不同模型选择（文生图/文生视频/图生视频）

节点连接右接左 单击连接线可删除

**需要复杂运镜时进入 3D 导演台**
对于人物走位、镜头运动、空间关系要求比较高的镜头，可以进入 **3D 导演台**，设置：
- 摄像机位置
- 人物位置
- 场景空间关系

## 4. 生成最终镜头 → 导出使用

最终得到每一个镜头的视频素材，再用于后续剪辑或成片制作

不满意的结果不需要覆盖原内容，可以保留不同版本，方便比较和继续延展

左键单击视频显示下载视频路径 历史素材位于底部导航栏

也可添加视频合成节点 在画布中合成视频

## 5. 底部导航栏图表 快捷键总览

# 二、一键生成AI短剧模式

## 1. 输入剧本 / 故事内容

生成剧本大纲（注意不宜有敏感词）
（如有积分不足情况，每日赠送积分为agnes video2.5专用积分）

## 2. 拆解角色与场景

自动提取主要角色、服装造型、场景地点、关键道具等内容，形成项目基础资产

**创建 / 导入角色与场景资产**
用户可以直接生成角色、场景，也可以从已有资产库中导入，并对人物和场景进行统一设定。

同一角色不同形象智能应用于不同剧情/剧集

按需选择生成道具/场景资产（不生成分镜中会自行生成 场景/道具不统一）

## 3. 剧本自动拆分分镜

3.1 选择文生视频/图生视频模式（不选择生成分镜图则是文生视频）

3.2 调整提示词无误 自行选择单个/批量生成视频 分镜秒数也可修改

生成视频不满意调整提示词即可重新生成 历史视频在右边查看

## 4. 点击分镜自行合成 生成最终视频

# 四、常见问题

## 台词问题

视频时长总长应符合 常规动作、台词说话时长 示例（模型agnes2.5）：12s

## 提示词规范 应至少包含以下要素：

运镜（手法），画风（2D /写实/CG），景别：（近景 / 中景 / 特写/全景），人物：台词（X）镜头切换流畅，及风格/氛围限制词

例：（模型seedance2.5）
