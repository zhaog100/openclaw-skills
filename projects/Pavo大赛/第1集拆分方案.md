## 📐 拆分方案：4场景 × 2片段 = 8个片段

### 拆分逻辑

每个场景15秒，拆分为2个片段，每个片段7-8秒：
- 片段1：前半段（0-7.5秒）
- 片段2：后半段（7.5-15秒）

**优点**：
- ✅ 片段短，AI生成更稳定
- ✅ 容错率高，某个片段不好可单独重生成
- ✅ 剪辑时可灵活调整节奏

| Final Cut Pro | ⭐⭐⭐ | 中等 | 付费 |

**推荐使用：剪映（电脑版）**

### 剪辑步骤

#### 第一步：导入素材
```
1. 打开剪映
2. 点击「开始创作」
3. 导入8个视频片段
4. 设置项目参数：1080p，30fps
```

#### 第二步：排列片段
```
时间轴顺序：
00:00-00:07  | 片段1-1（裂谷全景）
00:07-00:15 | 片段1-2（残旗黑烟）
00:15-00:22 | 片段2-1（萤华醒来）
00:22-00:30 | 片段2-2（指尖萤火）
00:30-00:37 | 片段3-1（萤火绽放）
00:37-00:45 | 片段3-2（枯骨发光）
00:45-00:52 | 片段4-1（巨灵浮现）
00:52-01:00 | 片段4-2（少女仰望）
```

#### 第三步：添加转场
```
- 场景1→场景2：叠化（0.5秒）
- 场景2→场景3：叠化（0.5秒）
- 场景3→场景4：叠化（0.5秒）
```

#### 第四步：添加字幕
```
旁白字幕：
- 00:00-00:15："天地初开，神魔纷争。截教兴衰，尽在劫数..."
- 00:15-00:30："千年之后，最后的传承者..."
- 00:30-00:45："她是最后的萤火，也是最后的希望..."
- 00:45-01:00："然而黑暗正在苏醒..."

悬念字幕（片尾）：
- "她将独自面对吗？"
```

#### 第五步：添加音频
```
1. 旁白配音（可用AI配音或真人录制）
2. 背景音乐（古风、悬疑风格）
3. 音效：
   - 风声呼啸（场景1）
   - 心跳声+微光音效（场景2）
   - 萤火嗡鸣+光芒绽放（场景3）
   - 震动声+黑暗涌动（场景4）
```

#### 第六步：导出
```
- 格式：MP4
- 分辨率：1080p
- 帧率：30fps
- 码率：建议10-15Mbps
```
