# 🌶️ Prompt Engineering 实战日志

## 2026-09-10 练习记录

### 练习1：思维链（Chain-of-Thought）

#### 测试1.1：简单数学
**Prompt：**
```
请逐步思考：
1. 首先计算每天下多少个蛋
2. 然后计算一周（7天）下多少个蛋
3. 展示你的计算过程
4. 最后给出答案

问题：一个农场有15只鸡，每只鸡每天下1个蛋。一周能收集多少个蛋？
```

**结果：**
- 模型能按步骤思考
- 计算过程清晰
- 答案正确：105个蛋

**心得：** 思维链对简单数学题效果明显，模型会展示推理过程。

---

#### 测试1.2：科学解释
**Prompt：**
```
请像物理老师一样解释：
1. 先描述光的本质
2. 解释光进入大气层后的行为
3. 说明不同颜色光的散射差异
4. 用简单的比喻总结
5. 最后给出完整解释

问题：为什么天空是蓝色的？
```

**结果：**
- 能分步骤解释
- 提到了瑞利散射
- 比喻可能不够准确

**心得：** 思维链让复杂概念更容易理解，但需要确保步骤合理。

### 练习2：少样本学习（Few-Shot）

#### 测试2.1：情感分类
**Prompt：**
```
示例：
输入："这部电影太精彩了！" → 输出："正面"
输入："食物很难吃，服务也很差" → 输出："负面"
输入："价格适中，环境一般" → 输出："中性"

现在请分类：
输入："刚收到的快递，包装完好，商品质量超出预期！" → 输出：?
```

**结果：**
- 模型正确分类为"正面"
- 学会了示例的模式

**心得：** Few-Shot能显著提升分类准确率，示例越典型越好。

---

#### 测试2.2：风格转换
**Prompt：**
```
示例：
原文："你好，请帮我处理一下这个问题"
→ 礼貌版："您好，麻烦您帮忙处理一下这个问题，谢谢！"

原文："这个功能有问题，赶紧修一下"
→ 礼貌版："您好，发现这个功能存在一些问题，能否协助修复一下？感谢！"

现在转换：
原文："你写的代码有bug，重新写"
→ 礼貌版：?
```

**结果：**
- 模型学会了礼貌表达的模式
- 输出了更委婉的表述

**心得：** Few-Shot适合风格迁移，示例要覆盖典型情况。

---

### 练习3：角色扮演

#### 测试3.1：小红书博主
**Prompt：**
```
你现在是一位小红书爆款内容创作者，擅长写探店文案。

请为一家新开的咖啡馆写推广文案，要求：
- 标题要有吸引力，使用emoji
- 正文控制在100字以内
- 包含：店铺亮点+个人体验+推荐理由
- 结尾加上热门标签
- 语气活泼，像朋友推荐
```

**结果：**
- 文案风格符合要求
- 使用了适当的emoji
- 结构完整

**心得：** 明确的角色设定能让输出更符合预期。

### 练习4：输出格式控制

#### 测试4.1：JSON提取
**Prompt：**
```
请提取以下文本中的关键信息，以JSON格式输出：

"小米椒咖啡屋位于朝阳区建国路88号，创始人张小明，2023年开业，主打手冲咖啡和甜点，人均消费45元，营业时间10:00-22:00"

要求格式：
{
  "店名": "",
  "地址": "",
  "创始人": "",
  "开业年份": ,
  "主打产品": [],
  "人均消费": ,
  "营业时间": ""
}
```

**结果：**
- JSON格式正确
- 信息提取完整

**心得：** 指定JSON Schema能确保结构一致，便于后续处理。

---

### 练习5：约束条件

#### 测试5.1：字数限制
**Prompt：**
```
请用不超过50字介绍什么是区块链。
要求：通俗易懂，避免专业术语，适合小学生理解。
```

**结果：**
- 成功控制在50字以内
- 使用了简单比喻

**心得：** 明确的字数限制有效，但可能牺牲细节。

## 📊 练习总结

### 最佳实践
1. **思维链** - 复杂问题拆步骤，效果显著提升
2. **少样本** - 提供2-3个示例，模型快速学会模式
3. **角色扮演** - 明确身份，输出更专业
4. **格式控制** - 指定JSON/表格，便于程序处理
5. **约束条件** - 字数/风格/禁止项，确保输出符合预期

### 常见问题
1. 示例太少 → 模型可能理解偏差
2. 步骤太复杂 → 小模型可能跟丢
3. 约束太严 → 输出可能生硬
