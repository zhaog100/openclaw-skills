# 🌶️ Prompt Engineering 练习题库

## 练习1：思维链（Chain-of-Thought）

### 基础版
```
问题：一个农场有15只鸡，每只鸡每天下1个蛋。一周能收集多少个蛋？

❌ 简单提示：直接问答案
✅ 思维链提示：
"请逐步思考：
1. 首先计算每天下多少个蛋
2. 然后计算一周（7天）下多少个蛋
3. 展示你的计算过程
4. 最后给出答案"
```

### 进阶版
```
问题：解释为什么天空是蓝色的

❌ 简单提示："为什么天空是蓝色的？"
✅ 思维链提示：
"请像物理老师一样解释：
1. 先描述光的本质
2. 解释光进入大气层后的行为
3. 说明不同颜色光的散射差异
4. 用简单的比喻总结
5. 最后给出完整解释"
```

## 练习2：少样本学习（Few-Shot）

### 情感分类
```
示例：
输入："这部电影太精彩了！" → 输出："正面"
输入："食物很难吃，服务也很差" → 输出："负面"
输入："价格适中，环境一般" → 输出："中性"

现在请分类：
输入："刚收到的快递，包装完好，商品质量超出预期！" → 输出：?
```

### 风格转换
```
示例：
原文："你好，请帮我处理一下这个问题"
→ 礼貌版："您好，麻烦您帮忙处理一下这个问题，谢谢！"

原文："这个功能有问题，赶紧修一下"
→ 礼貌版："您好，发现这个功能存在一些问题，能否协助修复一下？感谢！"

现在转换：
原文："你写的代码有bug，重新写"
→ 礼貌版：?
```

## 练习3：角色扮演

### 场景设定
```
角色：你是小红书爆款内容创作者
任务：写一篇探店文案

要求：
- 标题要有吸引力，使用emoji
- 正文控制在100字以内
- 包含：店铺亮点+个人体验+推荐理由
- 结尾加上热门标签
- 语气活泼，像朋友推荐
```

### 多轮对话
```
用户：我想开一家咖啡馆，帮我分析利弊

AI（作为商业顾问）：好的，我来帮您分析...

用户：我觉得你说的有道理，但预算有限怎么办？

AI（继续扮演）：理解您的顾虑，预算有限时可以考虑...
```

## 练习4：输出格式控制

### JSON格式
```
请提取以下文本中的关键信息，以JSON格式输出：

"小米椒咖啡屋位于朝阳区建国路88号，创始人张小明，2023年开业，主打手冲咖啡和甜点，人均消费45元，营业时间10:00-22:00"

要求格式：
{
  "店名": "",
  "地址": "",
  "创始人": "",
  "开业年份": ,
  "主打产品": [],
  "人均消费": ,
  "营业时间": ""
}
```

### 表格格式
```
请对比以下两种方案的优缺点，以Markdown表格输出：

方案A：使用本地模型（Ollama）
方案B：使用云端API（如OpenAI）

表格包含：成本、隐私、速度、易用性、适用场景
```

## 练习5：约束条件

### 字数限制
```
请用不超过50字介绍什么是区块链。
要求：通俗易懂，避免专业术语，适合小学生理解。
```

### 结构限制
```
请用"总-分-总"结构写一段关于健康饮食的建议：
- 总：一句话概括核心理念
- 分：3个具体建议（每条不超过20字）
- 总：一句话总结
```

### 禁止事项
```
请解释人工智能的基本概念：
- 禁止使用技术术语
- 禁止超过100字
- 必须使用比喻手法
- 避免提到任何公司名称
```
