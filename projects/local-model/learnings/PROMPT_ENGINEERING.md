# 🌶️ Prompt Engineering 学习笔记

## 基础技巧

### 1. 明确角色设定
```
❌ 坏提示："解释机器学习"
✅ 好提示："请用简单的语言解释什么是机器学习，适合小学生理解"
```

### 2. 指定输出格式
```
❌ 坏提示："写一个文案"
✅ 好提示："请写一个朋友圈文案，宣传小红书的探店内容创作，要求：
- 50字以内
- 包含emoji
- 吸引年轻人"
```

### 3. 提供上下文
```
❌ 坏提示："写个报告"
✅ 好提示："请写一份关于Qwen2.5模型的性能测试报告，
要求：
- 包含模型参数说明
- 测试环境配置
- 推理速度数据
- 内存占用分析"
```

### 4. 分步指令
```
❌ 坏提示："帮我优化这个函数"
✅ 好提示："请帮我优化这段Python代码：
1. 首先分析代码的问题
2. 然后提供优化建议
3. 最后写出优化后的代码
4. 添加详细注释"
```

## 进阶技巧

### Chain-of-Thought (思维链)
```
"让我们一步步思考：
1. 这个问题涉及什么知识点？
2. 我应该考虑哪些因素？
3. 如何验证答案的正确性？
请详细展示你的思考过程。"
```

### Few-Shot Learning (少样本学习)
```
"请参考以下示例的格式：
示例1：输入='你好'，输出='您好！'
示例2：输入='谢谢'，输出='不客气！'
现在请处理：输入='再见'，输出='?'
"
```

### 角色扮演
```
"你现在是一位经验丰富的AI工程师，
精通大语言模型的原理和应用。
请用专业的角度分析这个问题..."
```

## 实战案例

### 案例1：技术问答
```
❌ "什么是Transformer？"
✅ "请用通俗的语言解释Transformer架构的核心思想，
重点说明Self-Attention机制的工作原理，
并举一个具体的应用例子。"
```

### 案例2：代码生成
```
❌ "写一个排序函数"
✅ "请写一个Python函数实现快速排序算法，
要求：
- 支持自定义比较函数
- 添加类型注解
- 包含完整的文档字符串
- 提供使用示例"
```

### 案例3：内容创作
```
❌ "写一篇文章介绍AI"
✅ "请写一篇关于大语言模型发展史的科普文章，
要求：
- 面向普通读者，避免专业术语
- 包含关键时间节点和里程碑事件
- 提及3-5个代表性模型（GPT、BERT、PaLM等）
- 结尾展望未来发展趋势
- 字数控制在800-1000字"
```

## 避免的常见错误

1. **提示过于模糊** → 缺少具体要求和约束
2. **一次要求太多** → 拆分成多个步骤
3. **缺少上下文** → 提供必要的背景信息
4. **没有指定格式** → 明确输出格式要求
5. **角色不明确** → 指定AI应该扮演的角色

## 练习建议

1. **每天测试3-5个不同类型的提示**
2. **记录成功和失败的案例**
3. **对比不同模型的响应质量**
4. **学习优秀提示的写法**
5. **持续迭代优化**
