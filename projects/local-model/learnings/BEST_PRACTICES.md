## 一、思维链（Chain-of-Thought）最佳实践

### 案例1：数学推理
```
❌ 差提示："15只鸡一周下多少个蛋？"
✅ 好提示：
请逐步思考并计算：
1. 先算每天下多少个蛋
2. 再算一周（7天）总共下多少个
3. 列出计算式
4. 给出最终答案
问题：农场有15只鸡，每只每天下1个蛋，一周能收集多少个蛋？
```
**效果**：⭐⭐⭐⭐⭐ 输出完整推理过程，答案准确

### 案例2：科学解释
```
❌ 差提示："为什么天空是蓝色的？"
✅ 好提示：
请像物理老师一样解释：
1. 先描述光的本质（什么光）
2. 解释光进入大气层后发生什么
3. 说明不同颜色光的散射差异
4. 用简单比喻帮助理解
5. 最后给出完整解释
```
**效果**：⭐⭐⭐⭐ 提到瑞利散射，比喻略生硬

### 案例3：逻辑推理
```
✅ 好提示：
让我们一步步分析：
1. 梳理题目中的已知条件
2. 找出关键逻辑关系
3. 排除干扰信息
4. 推导最终结论
5. 验证答案是否合理
```
**效果**：⭐⭐⭐⭐⭐ 小模型也能跟上进阶思维链

## 二、少样本学习（Few-Shot）最佳实践

### 案例1：情感分类
```
✅ 好提示：
示例：
输入："这部电影太精彩了！" → 输出："正面"
输入："食物很难吃，服务也很差" → 输出："负面"
输入："价格适中，环境一般" → 输出："中性"

现在请分类：
输入："刚收到的快递，包装完好，商品质量超出预期！" → 输出：?
```
**效果**：⭐⭐⭐⭐⭐ 模型正确分类，学会模式

### 案例2：风格转换
```
✅ 好提示：
原文："你好，请帮我处理一下这个问题"
→ 礼貌版："您好，麻烦您帮忙处理一下这个问题，谢谢！"

原文："这个功能有问题，赶紧修一下"
→ 礼貌版："您好，发现这个功能存在一些问题，能否协助修复一下？感谢！"

现在转换：
原文："你写的代码有bug，重新写"
→ 礼貌版：?
```
**效果**：⭐⭐⭐⭐ 成功学会委婉表达

### 案例3：数据提取
```
✅ 好提示：
示例1：
文本："苹果iPhone15售价7999元"
输出：{"品牌": "苹果", "产品": "iPhone15", "价格": 7999}

示例2：
文本："华为Mate60售价5999元"
输出：{"品牌": "华为", "产品": "Mate60", "价格": 5999}

现在提取：
文本："小米14售价3999元"
输出：?
```
**效果**：⭐⭐⭐⭐⭐ JSON格式稳定输出

## 三、角色扮演最佳实践

### 案例1：小红书博主
```
✅ 好提示：
你现在是一位小红书爆款内容创作者，擅长写探店文案。

请为一家新开的咖啡馆写推广文案，要求：
- 标题要有吸引力，使用emoji
- 正文控制在100字以内
- 包含：店铺亮点+个人体验+推荐理由
- 结尾加上热门标签
- 语气活泼，像朋友推荐
```
**效果**：⭐⭐⭐⭐ 风格到位，结构完整

### 案例2：技术顾问
```
✅ 好提示：
你是一位资深前端工程师，正在指导初级开发者。
请用鼓励的语气解释以下问题：
[具体问题]
要求：
- 先肯定问题的价值
- 用通俗比喻解释概念
- 给出可操作的解决方案
- 最后给予鼓励
```
**效果**：⭐⭐⭐⭐⭐ 语气自然，解释清晰

## 五、约束条件最佳实践

### 案例1：字数限制
```
✅ 好提示：
请用不超过50字介绍什么是区块链。
要求：通俗易懂，避免专业术语，适合小学生理解。
```
**效果**：⭐⭐⭐⭐ 成功控长，牺牲部分细节

### 案例2：结构限制
```
✅ 好提示：
请用"总-分-总"结构写一段关于健康饮食的建议：
- 总：一句话概括核心理念
- 分：3个具体建议（每条不超过20字）
- 总：一句话总结
```
**效果**：⭐⭐⭐⭐ 结构清晰，符合预期

### 案例3：禁止事项
```
✅ 好提示：
请解释人工智能的基本概念：
- 禁止使用技术术语
- 禁止超过100字
- 必须使用比喻手法
- 避免提到任何公司名称
```
**效果**：⭐⭐⭐ 能遵守大部分约束，偶尔越界

### ❌ 常见失败模式
| 问题 | 表现 | 解决 |
|------|------|------|
| 提示模糊 | 输出太泛 | 加具体约束 |
| 步骤过多 | 小模型跟丢 | 简化为3-4步 |
| 缺少示例 | 理解偏差 | 加1-2个few-shot |
| 约束矛盾 | 输出混乱 | 检查约束一致性 |
| 格式不指定 | 结构无序 | 给出模板 |

### 📊 效果评级标准
- ⭐⭐⭐⭐⭐：输出完全符合预期，可直接使用
- ⭐⭐⭐⭐：基本符合，需微调
- ⭐⭐⭐：能用但质量一般
- ⭐⭐：需要大幅修改
- ⭐：效果很差，需重写
