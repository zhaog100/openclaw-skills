# 小红书爆款运营指南

## 一、标题公式

### 1. 爆款标题结构
```
核心卖点 + 人群标签 + 场景 + 数字 + 情绪词
```

### 2. 经典公式示例
| 公式 | 示例 |
|------|------|
| 痛点+解决方案 | "熬夜党必看！3个方法让我皮肤变好了" |
| 数字+效果 | "用了28天，我的痘印淡了80%" |
| 反差+好奇 | "从月薪3千到月入3万，我只做了这件事" |
| 权威+背书 | "小红书Top10博主同款，终于懂了" |

### 3. 标题禁忌
- ❌ 避免夸张虚假："100%有效"、"绝对好用"
- ❌ 避免长句：控制在20字以内
- ❌ 避免生僻词：确保大众能看懂

---

## 二、发布时间策略

### 最佳发布时间
| 时段 | 时间段 | 适合内容 |
|------|--------|----------|
| 早高峰 | 7:00-9:00 | 早餐、穿搭、正能量 |
| 午休 | 12:00-13:00 | 美食、生活分享 |
| 晚高峰 | 18:00-20:00 | 干货、教程、种草 |
| 睡前 | 21:00-23:00 | 情感、故事、轻松内容 |

### 测试建议
- 同一类型内容在不同时段发布
- 观察2周数据，找到最佳发布时间
- 周末时间可适当延后1小时

---

## 三、内容创作规范

### 1. 图文规范
- **封面**：高清、美观、有吸引力
- **图片数量**：4-9张最佳
- **文案长度**：100-300字
- **标签数量**：5-10个

### 2. 热门话题标签
| 类别 | 推荐标签 |
|------|----------|
| 生活 | #日常 #生活记录 #好物分享 |
| 美妆 | #化妆教程 #护肤心得 #美妆测评 |
| 穿搭 | #OOTD #穿搭技巧 #显瘦穿搭 |
| 美食 | #美食日常 #家常菜 #烘焙 |

### 3. 互动引导
- 结尾加问句："你们觉得呢？"
- 设置投票："A还是B？"
- 鼓励评论："评论区告诉我你的想法"

---

## 四、数据分析指标

### 核心指标
| 指标 | 说明 | 优秀标准 |
|------|------|----------|
| 点击率 | 封面吸引力 | >5% |
| 完播率 | 内容质量 | >30% |
| 互动率 | 用户粘性 | >3% |
| 涨粉率 | 转化效果 | >1% |

### 数据复盘周期
- 每日：检查昨日数据
- 每周：分析趋势变化
- 每月：总结爆款规律
