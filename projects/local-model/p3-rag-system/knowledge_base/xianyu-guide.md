# 闲鱼卖货实战经验

## 一、选品策略

### 1. 选品原则
- 低客单价：50-200元区间成交率高
- 高复购：消耗品、配件类优先
- 轻物流：体积小、重量轻、不易损
- 差异化：避免和平台爆款直接竞争

### 2. 热门品类
| 品类 | 利润率 | 难度 | 备注 |
|------|--------|------|------|
| 数码配件 | 40-60% | 低 | 充电器、数据线 |
| 服装配饰 | 50-80% | 中 | 季节性强 |
| 家居用品 | 30-50% | 低 | 收纳、小家电 |
| 虚拟商品 | 80%+ | 中 | 教程、素材 |

---

## 二、文案技巧

### 1. 标题公式
```
品牌 + 型号 + 核心卖点 + 成色 + 价格
```

**示例：**
- ❌ "转让iPhone"
- ✅ "苹果iPhone12 128G 国行 8成新 已验机 保30天"

### 2. 描述要点
- 真实描述瑕疵（避免纠纷）
- 突出使用场景
- 说明转让原因
- 提供联系方式

### 3. 定价策略
| 成本 | 定价建议 |
|------|----------|
| 1688进货 | 3-5倍定价 |
| 二手回收 | 成本+30-50%利润 |
| 闲置转让 | 市场价的50-70% |

---

## 三、运营技巧

### 1. 发布时间
- 早8-9点：上班族起床刷
- 午12-13点：午休时间
- 晚20-22点：黄金时段

### 2. 擦亮技巧
- 每天定时擦亮（早晚各一次）
- 下架重发（权重更高）
- 标题关键词轮换

### 3. 客服话术
```
买家问：还在吗？
回复：在的哦~ 今天可以发货！

买家问：能便宜吗？
回复：已经是最优惠啦~  quality保证！

买家问：什么时候发货？
回复：下午4点前下单当天发，次日达~
```

## 四、数据复盘

### 1. 核心指标
| 指标 | 计算方法 | 参考值 |
|------|----------|--------|
| 曝光率 | 浏览量/曝光次数 | >30% |
| 咨询率 | 咨询量/浏览量 | >5% |
| 转化率 | 成交量/咨询量 | >20% |

### 2. 优化方向
- 曝光低 → 优化标题、擦亮、换图
- 咨询低 → 优化描述、增加详情图
- 转化低 → 优化价格、客服响应
