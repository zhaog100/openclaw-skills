# 📝 小红书爆款标题公式

**来源**: 小红书运营技能库
**最后更新**: 2026-08-23

---

## 🎯 爆款标题4要素

1. **核心卖点** — 产品最吸引人的特点
2. **目标人群** — 谁会需要
3. **使用场景** — 什么时候/在哪里用
4. **数字** — 价格/时间/数量
5. **情绪词** — 惊喜/后悔没早买

---

## ✅ 标题公式模板

### 公式1：痛点+解决方案+数字
```
打工人救星！3.9元蒸汽眼罩，戴1次加班不累了
```

### 公式2：疑问+反差+结果
```
60岁被问40岁了吧？抗老秘诀曝光！
```

### 公式3：场景+痛点+解决方案
```
五一宅家连看3部电影🎬眼睛干涩到流泪？
```

### 公式4：热点+切入+价值
```
榴莲价格跳水🥭打工人实现榴莲自由！
```

---

## ⚠️ 禁用词

- ❌ 最、第一、唯一、绝对
- ❌ 100%有效、根治、治愈
- ❌ 虚假承诺、夸大功效

---

## 📊 标题检查清单

- [ ] 含数字或疑问句
- [ ] ≤20字
- [ ] 有情绪词或痛点
- [ ] 无禁用词
- [ ] 与内容相关
