|------|---------|------|---------|
| 实物打底仓持有量（克） | 3:4:3 分批进度 | | |

## 周度决策规则

```
周一/二: 看盯价推了没（888/871 有没有跌破）
   → 跌到 888: 实物仓补 40%（2800 元）
   → 跌到 871: 实物仓补 30%（2100 元）
   → 没跌破: 本周不新增买入

周三: 看 942/974 有没有涨破
   → 涨到 942: 波段仓减 1/3（1000 元）
   → 涨到 974: 波段仓再减 1/3（1000 元）
   → 没涨破: 持有不动

周五: 复盘（盯价自动推本周汇总）
   → 填写上方 6 项指标
   → 波段仓净盈亏 = (卖出价 - 买入价 - 34 点差) × 卖出克数
   → 调整下周买卖点（数据源动态滚动）
```

## 波段仓净盈亏公式（扣点差）

```
单仓净盈亏 = (卖出价 - 买入价 - 34) × 克数
   34 = 点差 17 × 2（买入 +17、卖出 -17）

例: 894 买、942 卖 1000 克
   净盈亏 = (942 - 894 - 34) × 1000 = 14 元/克 × 1000 = 14,000 元
   收益率 = 14/894 = 1.57%（一周内，扣点差后）
```
