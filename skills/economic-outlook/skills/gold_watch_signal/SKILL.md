# gold_watch_signal — 黄金盯价信号

## 口径铁律（勿破，官家11-01 定稿）

**下单锚 = 上金所 Au99.99 现货（≈833 量级），不是期货。**
- 855（沪金主力期货 AUM）/ 867·873（官网日终快照）**全部禁止当实时下单锚**——比现货偏高 20~34 元，出假信号。
- 上金所**没有面向公众的官方实时 tick API**：真正的秒级实时只走会员交易终端 / Wind / Bloomberg（付费）。所有"实时"渠道本质是**第三方从上金所采集转发的准实时（秒~分钟延迟）**，够用但不算官方实时。

## 数据链路

### ① 下单锚（实时准，任一通即出 833 现货口径）
`skill.py: _fetch_au0_realtime()` 降级链：
1. 东财 118.AU9999（f43 最新价，多节点并发+2.5s 超时）
2. 金投网 jijinhao JO_71，**只取 q5 最新价**（q2=昨收 854.76 虚高 ~22 元，禁用）→ 打 `degraded=True`
3. 官网 `/graph/quotations`（`heyue=Au99.99`，data 末值=最新挂单价，准实时快照）→ 打 `degraded=True`
4. 全挂才落 au0 期货日线（偏高 ~22 元，标 degraded，不静默冒充现货）

`degraded=True` 的口径：outcome 层**只展示、不自动触发申购/赎回**（防降级偏高误下单）。

### ② 档位基准（日线，算 20/60 日高低点·MA·买卖点用）
- 官网 Dailyhq `/graph/Dailyhq`（`instid=Au99.99`，上金所现货日线，口径正）——**只喂档位，不喂下单价**（末行=最近交易日日收，如 10-30 收 867，比实时偏高，当锚会误判破档）。
- 东财 AU9999 K 线（备）。

## 品种 instid 对照（官网 Dailyhq 可查）
Au99.99 / Au99.95 / Au100g / Au(T+D) / mAu(T+D) / Ag(T+D) / Pt99.95。
返回统一 `{"time":[[date,open,high,low,close,volume],...]}`，取末行。
查不到：银行间询价(auy.cny/pau99.99)、国际板、上海金早盘/午盘价（需官网首页行情板块另解析）。

## 不接的东西（避免过度设计）
探数/极速/GoldAPI 等**第三方付费聚合 API（要 AppCode/appkey、限流 429、口径杂、合规灰）**——现有免费准实时转源已够低频分批需求，不引入。
