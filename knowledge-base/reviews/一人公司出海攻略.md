# 一人公司出海全套攻略

**来源**：独立开发者出海指南
**收录日期**：2026-04-15
**核心观点**：一人公司出海，成本可控制在5000元以内，2-4周就能全部搞定

---

## 🎯 为什么是一人公司？

### 1. 成本极低
- 传统公司出海：租办公室 + 雇员工 + 养团队
- 一人公司：你自己就是全部
- 独立开发者月成本 < 100美金，却服务全球用户

### 2. 决策极快
- 换技术栈：不用开会讨论，自己决定
- 做新功能：今晚就能上线
- 灵活性：大公司无法比拟

### 3. 天花板极高
- 海外市场付费意愿与国内完全不同量级
- 9.9美金/月小工具 + 1000付费用户 = 月收入7万人民币
- 这是"睡后收入"，系统自动化运转

**真实案例**：
- Notion模板朋友：50多个模板，月被动收入1.2万美金
- 学术写作AI工具：月收入4.5万美金，用户才3000多人

## 🗺️ 注册海外公司：选哪里？

### 三地对比一览

| 对比项 | 香港 | 美国LLC | 新加坡 |
|-------|------|---------|--------|
| **注册成本** | 3000-5000元 | 1500-2000元 | 8000-15000元 |
| **年维护费** | 2000-4000元 | 500-1000元 | 3000-5000元 |
| **税务** | 利得税16.5% | 穿透征税 | 17%企业所得税 |
| **Stripe友好度** | 中等 | 最高 | 中等 |
| **适合人群** | 亚洲市场 | SaaS/AI工具 | 高端品牌 |

### 建议
- **首选**：美国LLC（特拉华州或怀俄明州）
  - Stripe对美国公司最友好，开户成功率最高
  - 怀俄明州没有州所得税，维护成本最低
- **次选**：香港公司
  - 亚洲市场或频繁和国内打交道
- **新加坡**：高端玩家，适合一定规模后考虑

### 美国LLC注册实操（怀俄明州）
**流程**：
1. 选择注册代理：Firstbase、LegalZoom，费用约100-200美金
2. 提交注册申请：公司名称、股东信息（可只有你一人）、注册地址
3. 申请EIN税号：相当于美国公司身份证号，免费申请
4. 编制运营协议：明确公司规则和股权结构

**费用总结**：
- 注册费：约100-150美金
- 代理服务费：约100美金/年
- EIN申请：免费
- 首年总成本：约1500-2000人民币

## 💰 银行开户与全球收款

### 1. 海外银行账户

**传统银行**：汇丰、渣打
- 门槛高、审核严，对一人公司不太友好

**初创友好选择**：
- **Mercury（强烈推荐）**：美国数字银行，专为初创公司设计
  - 全程在线申请，无需亲临美国
  - 对美国LLC特别友好
  - 免费开户，没有最低余额要求
- **Wise Business**：支持多币种账户，汇率透明，适合收款后换汇
- **万里汇（WorldFirst）**：阿里旗下，对国内用户友好，结汇回国方便

### 2. 支付网关

**银行账户存钱，支付网关收钱**

- **Stripe（首选）**：
  - 全球最流行的支付网关
  - 支持信用卡、借记卡、Apple Pay、Google Pay等
  - 手续费2.9% + 0.3美金/笔，T+7到账
  - 对美国公司开户成功率最高
- **PayPal Business**：
  - 全球用户基数大
  - 手续费较高（4.4% + 固定费用）
  - 容易风控冻结，建议作为备用渠道
- **Paddle / LemonSqueezy**：
  - 适合SaaS订阅业务
  - 帮你处理税务合规（VAT/GST）
  - 手续费更高（5%+）

### 3. 完整收款流程
> 用户付款 → Stripe → 美国银行账户 → Wise → 国内银行卡/支付宝
>
> 整个流程下来，手续费约3-4%，比第三方代收款便宜一半以上。

**技巧**：Wise可以绑定微信"香港钱包"，国内直接用微信支付消费海外收入，非常方便。

## 📋 税务合规：别踩红线

### 1. 美国税务
- 美国LLC默认是"穿透实体"，公司本身不缴税，利润直接算到个人头上
- 如果不是美国税务居民，只需就"美国来源收入"缴税
- **技巧**：如果客户都在海外，收入可被视为"外国来源收入"，可能不需要在美国缴税

### 2. 中国税务
- 作为中国税务居民，全球收入都需要在中国申报
- 中美有税收协定，可以避免双重征税

**重要提醒**：
1. 每年5月31日前完成美国公司年报
2. 保留所有收入和支出凭证
3. 如果年收入超过12万人民币，建议找专业会计师报税
4. 不要试图隐瞒收入，CRS全球税务信息交换已经很成熟

### 3. 增值税/销售税
- 欧洲客户：可能需要处理VAT（增值税）
- 美国客户：部分州要求收取销售税
- Stripe Tax和Paddle都可以自动帮你计算和代缴这些税费

## ⚠️ 避坑指南：这些雷别踩

### 坑1：用个人PayPal收企业款
- 风控极严格，收了几笔大额款项后账户可能被永久冻结
- 千万别冒险

### 坑2：忽视GDPR/CCPA合规
- 欧洲或加州用户：必须遵守数据隐私法规
- 最简单做法：网站底部加隐私政策页面
- 可用iubenda.com这样的工具一键生成

### 坑3：空壳公司秒收大额
- 新注册公司直接收大额款项，容易被风控
- 建议先从小额交易开始，慢慢积累信用记录
- 准备业务说明、客户合同等证明材料

### 坑4：只做单平台部署
- 只做iOS App，放弃Android用户，直接损失40%市场
- 建议优先做Web版本，一套代码覆盖所有平台

### 坑5：忽视本地化
- 不是把界面翻译成英文就完事了
- 真正的本地化包括：
  - 货币显示（$299.00 而不是 ￥299.00）
  - 日期格式（MM/DD/YYYY）
  - 时区处理
  - 客服时区覆盖

**20个避坑清单（精简版）**：
- ✓ 别用个人PayPal收企业款
- ✓ 别忽视GDPR/CCPA合规
- ✓ 别空壳公司秒收大额
- ✓ 别只做单平台
- ✓ 别忽视本地化
- ✓ 别用黑产代开广告账户
- ✓ 别和ChatGPT绑死不做缓存
- ✓ 别忘记备份数据

- 结果：月收入4.5万美金，用户才3000多人，客单价很高

- 结果：月被动收入1.2万美金，几乎不需要维护

### 案例3：邮件插件
- 产品：Gmail插件，帮助用户管理邮件
- 策略：定价9.9美金/月

1. 专注细分场景，不做大而全
2. 尽早收费，哪怕只有1美金
3. 利用社区传播，降低获客成本
4. 自动化运营，减少人工干预
