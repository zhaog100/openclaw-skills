# 外贸报价与成本计算公式

**收录日期**：2026-04-15
**来源**：外贸专业计算体系
**应用**：出口贸易定价、成本核算、利润分析
**维护**：小米椒 🌶️‍🔥

---

## 📦 一、报价与成本计算

### 1. FOB价格公式
```
FOB价 = (产品成本 + 国内费用 + 预期利润) / 汇率
```

### 2. CFR价格公式
```
CFR价 = FOB价 + 海运费
```

### 3. CIF价格公式
```
CIF价 = CFR价 + 保险费
     = FOB价 + 海运费 + 保险费
```

### 4. 出口退税计算
```
退税额 = 出口商品购进价(含增值税) ÷ (1+增值税率) × 退税率
```

### 5. 实际采购成本
```
实际采购成本 = 采购成本 - 出口退税额
```

### 6. 换汇成本计算
```
换汇成本 = 出口总成本(人民币) / FOB外汇净收入(美元)
```

### 7. 出口盈亏率
```
盈亏率 = (FOB外汇净收入×银行外汇买入价 - 出口总成本) / 出口总成本 × 100%
```

## 🚢 二、运费与保险费计算

### 1. 海运整箱运费
```
总运费 = 基本运费 + 港口附加费 + 燃油附加费 + 其他附加费
```

### 2. 海运拼箱运费
```
拼箱运费 = (货物体积或重量 × 费率) + 附加费
```

### 3. 空运运费计算
```
空运费 = 计费重量 × 适用费率
(计费重量取实际重量与体积重量中的较大值)
```

### 4. 体积重量计算
```
体积重量(kg) = 长(cm)×宽(cm)×高(cm) / 6000 (空运)
            或 / 5000 (部分海运)
```

### 5. 保险费计算
```
保险费 = CIF价 × (1+投保加成率) × 保险费率
```

---

## 💰 三、利润与佣金计算

### 1. 利润率计算
```
利润率 = (销售收入 - 总成本) / 总成本 × 100%
```

### 2. 外汇利润率
```
外汇利润率 = (外汇收入 - 外汇支出) / 外汇支出 × 100%
```

### 3. 佣金计算
```
含佣价 = 净价 / (1 - 佣金率)
佣金 = 含佣价 × 佣金率
```

---

## 🏛️ 四、关税与增值税计算

### 1. 进口关税计算
```
关税 = CIF价 × 关税税率
```

### 2. 进口增值税计算
```
增值税 = (CIF价 + 关税 + 消费税) × 增值税率
```

### 3. 消费税计算
```
消费税 = (CIF价 + 关税) / (1 - 消费税率) × 消费税率
```

---

## 💱 五、汇率与金融计算

### 1. 外汇保值计算
```
远期外汇保值成本 = 即期汇率 × (1 + 远期点数 / 10000)
```

### 2. 本币折算外币
```
外币价格 = 本币价格 / 汇率
```

### 3. 外币折算本币
```
本币价格 = 外币价格 × 汇率
```

## 📦 六、装箱与运输计算

### 1. 集装箱装箱量计算
```
20尺柜：约28立方米，限重18吨
40尺柜：约58立方米，限重26吨
40尺高柜：约68立方米，限重26吨
```

### 2. 装箱数量计算
```
每箱数量 = 集装箱内容积 / (包装箱长×宽×高)
总装箱数 = 总件数 / 每箱数量
```

### 3. 海运滞箱费计算
```
滞箱费 = 滞箱天数 × 每日费率
```

## 📋 七、其他实用计算

### 1. MOQ成本计算
```
MOQ总成本 = (单位成本 × MOQ数量) + 运费 + 关税 + 其他费用
```

### 2. 订货周期计算
```
订货周期 = 生产时间 + 运输时间 + 清关时间 + 配送时间
```

### 3. 安全库存计算
```
安全库存 = (最大日销量 × 最长补货时间) - (平均日销量 × 平均补货时间)
```

### 4. 经济订货批量(EOQ)
```
EOQ = √[(2×年需求量×每次订货成本) / 单位产品年持有成本]
```

### 5. 验货抽样标准(AQL)
```
根据ISO 2859-1标准，按批量大小和AQL值确定抽样数量
```

### 6. 汇率波动影响计算
```
汇率损失/收益 = 合同金额 × (签约汇率 - 结算汇率)
```

## 💡 应用场景

### 场景1：1688代发出口
```
实际采购成本 = 1688价格 - 出口退税额
FOB价 = (实际采购成本 + 包装费 + 港杂费 + 利润) / 汇率
```

### 场景2：跨境电商定价
```
CIF价 = FOB价 + 国际运费 + 保险费
售价 = CIF价 + 平台佣金 + 平台交易费
```

### 场景3：利润率核算
```
总成本 = 采购成本 + 运费 + 关税 + 平台费
利润率 = (售价 - 总成本) / 总成本 × 100%
```

## 🎯 关键要点

1. **FOB/CFR/CIF区分**：
   - FOB：船上交货（买家负责海运费和保险费）
   - CFR：成本加运费（买家负责保险费）
   - CIF：成本加保险费加运费（卖家负责运费和保险费）

2. **计费重量原则**：
   - 空运：取实际重量与体积重量中较大值
   - 海运：按实际重量或体积重量计费

3. **汇率风险管理**：
   - 签约时确定汇率
   - 或使用远期外汇保值
   - 避免汇率波动影响利润

4. **出口退税**：
   - 降低实际采购成本
   - 提高出口竞争力
   - 按国家规定的退税率计算

## 📝 计算示例

### 示例1：蒸汽眼罩FOB报价
```
产品成本：¥3.5/个
包装费：¥0.5/个
港杂费：¥1.0/个
预期利润：¥2.0/个
汇率：7.2（1美元=7.2人民币）

FOB价 = (3.5 + 0.5 + 1.0 + 2.0) / 7.2
      = 7.0 / 7.2
      = $0.97/个
```

### 示例2：蒸汽眼罩CIF报价
```
FOB价：$0.97/个
海运费：$0.15/个
保险费：$0.03/个（3%×1.1×$0.97）

CIF价 = 0.97 + 0.15 + 0.03
      = $1.15/个
```
