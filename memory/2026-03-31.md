## 📝 学习经验

1. **Gateway Cron 配置方法** ✨⭐⭐⭐
   - 使用 `openclaw cron add` 巻加定时任务
   - 任务默认为 `--announce` 模式，   - 可以指定 `--channel` 和 `--to` 参数
   - 配置完成后 Gateway 会自动加载

2. **Git 推送分支不匹配问题** ✨⭐⭐⭐
   - 错误：`src refspec main does not match any`
   - 原因：远程仓库默认分支是 main，本地是 master
   - 解决：`git push remote local:remote`
   - 例如：`git push xiaomijiao master:main`
   - 如果有冲突需要先 pull 再 push

3. **QMD 安装与配置** ✨⭐⭐⭐
   - 安装：`bun add -g @tobilu/qmd@2.0.1`
   - 创建集合：`qmd collection add . --name xiaomijiao --mask "**/*.md"`
   - 嵌入向量：`qmd embed --collection xiaomijiao`
   - 首次使用会下载嵌入模型（~328MB）

4. **Token 管理** ✨⭐⭐
   - 不同用途使用不同 token
   - 任务 token 和推送 token 分开存储
   - 在 URL 中嵌入 token 可以绕过认证提示
