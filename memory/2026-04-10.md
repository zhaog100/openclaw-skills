## 📚 今日学到

### 多通道记忆整合方案 ⭐⭐⭐⭐⭐
- **问题**：OpenClaw 每个通道创建独立会话，QQ对话不进记忆文件
- **根因**：cron 脚本只读 memory/ + git status，不读 session jsonl
- **时区坑**：session 存 UTC 时间，北京时间 07:41 = UTC 前一天 23:41
- **方案**：新增 do_extract_chats() → 从 sessions.json 遍历所有 jsonl
- **技能化**：multi-channel-memory v1.0.0 替换内嵌脚本，更完整（190条 vs 55条）
- **输出**：agents/xiaomijiao/memory/chat-YYYY-MM-DD.md，标注通道来源

### cron 脚本维护经验 ⭐⭐⭐⭐
- **line 228 bug**：grep -c 结果含换行，改为 `grep -c || true`
- **远程仓库**：脚本里写 xiaomila-skills.git（错）→ xiaomijiao-skills.git（对）
- **GitHub Token**：脚本里的 Token 与 git remote 需定期同步

### 飞书云文档权限 ⭐⭐⭐
- docx:document:create 权限未开通，无法 API 创建云文档
- 需在飞书开放平台手动开通后发布新版本

### 百炼 API Key 更新 ⭐⭐⭐
- 更新 openclaw.json 中的 apiKey 字段
- 需重启 Gateway 生效
- 重启方式：pkill -f openclaw-gateway，主程序自动拉起新进程
