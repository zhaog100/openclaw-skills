## 📚 今日学到

### 多通道记忆整合方案 ⭐⭐⭐⭐⭐
- **问题**：OpenClaw 每个通道创建独立会话，QQ对话不进记忆文件
- **根因**：cron 脚本只读 memory/ + git status，不读 session jsonl
- **时区坑**：session 存 UTC 时间，北京时间 07:41 = UTC 前一天 23:41
- **方案**：新增 do_extract_chats() → 从 sessions.json 遍历所有 jsonl
- **技能化**：从 openclaw-skills 仓库安装 multi-channel-memory v1.0.0
- **输出**：memory/chat-YYYY-MM-DD.md，标注通道来源

### cron 脚本维护经验 ⭐⭐⭐⭐
- **line 228 bug**：`grep -c` 结果含换行导致 integer expression expected，改为 `grep -c || true`
- **远程仓库地址**：脚本里写的是 xiaomila-skills.git（错误），git remote 实际是 xiaomijiao-skills.git
- **GitHub Token**：脚本里的 Token 与 git remote 不同步，需定期检查

### 飞书云文档权限 ⭐⭐⭐
