## ⚠️ 问题记录

### Subagent 频繁秒退/超时
- 原因: 智谱 GLM-5 限流（429）、仓库太大 clone 超时
- 影响: 约 30% 的 subagent 需要手动处理或重试
- 解决: 控制并发 3 个以内，大仓库手动处理

### GitHub API 限流
- 原因: 一天提交 60+ PR，API 调用量过大
- 解决: 等待 5 分钟自动恢复

### SolFoundry 推送问题
- 原因: 仓库太大（含 LFS），clone/push 超时
- 解决: 浅克隆 + force push 到 fork

3. **CodeRabbit 反馈要及时处理** — 提高合并概率
