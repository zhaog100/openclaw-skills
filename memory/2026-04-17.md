## 百炼模型终极修复（09:05-11:09）⭐⭐⭐⭐⭐

### 根因（四层叠加）
1. **L1**: Provider 名 "bailian" 非内置名 → Gateway 不认识 → 404
2. **L2**: 手动编辑 JSON 的 baseUrl 被 Gateway 用 `new URL().origin` 丢掉 `/v1` 路径 → 404
3. **L3**: Fallback 成功后 Gateway 自动写入 session override → 锁死会话
4. **L4**: 404 后 auth profile 进入 cooldown → 后续请求直接跳过

### 最终解决方案
- **正确 provider 名**: `modelstudio`（OpenClaw 内置），Gateway 内部映射为 `qwen`
- **正确配置方式**: `openclaw models auth add` → custom → modelstudio → default → 粘贴 key
- **错误方式**: 手动编辑 openclaw.json / auth-profiles.json（URL 构造会出错）
- **Coding Plan baseUrl**: `coding.dashscope.aliyuncs.com/v1`（内置，不要手动配）

### 改模型三件套
1. 清理 sessions.json 的 modelOverride 字段
2. 更新所有 cron 任务 model
3. 清理 auth-state.json 的 cooldownUntil 字段

### 踩坑记录
| 错误操作 | 结果 |
|----------|------|
| 手动编辑 openclaw.json 加 apiKey | Gateway 不读这个字段 |
| 手动编辑 auth-profiles.json | URL 构造丢 /v1 → 404 |
| Provider 名用 "bailian" | Gateway 不认识 → 404 |
| baseUrl 带 /v1 手动配 | Gateway 用 .origin 丢掉路径 |
| 只改 openclaw.json 不改 models.json | models.json 覆盖 |
