## 经验教训
1. BusyBox grep 不支持 -P 参数，用 sed 替代
2. crontab 脚本路径要写绝对路径或 cd 到目录
3. OpenClaw 升级后需要重启 gateway 服务
4. 创建 cron 任务前先确认脚本是否存在
5. openclaw-skills 是子模块，绝对不要修改和推送
6. nginx/ufw 等命令需要加 /usr/sbin 到 PATH
7. htpasswd 参数顺序：htpasswd -cbB 文件 用户名 密码
