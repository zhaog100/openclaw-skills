## 📚 今日学到

### Public-APIs-Poof API调研 ⭐⭐⭐⭐⭐
- **API信息**: Poof - Background Removal API（https://poof.bg/）
- **核心功能**: AI驱动背景移除，支持PNG/JPEG/WebP，像素级精准度
- **集成方式**: REST API + Python SDK + TypeScript SDK
- **API端点**: https://api.poof.bg/v1/remove
- **认证方式**: Header x-api-key（以poof_开头）
- **参数选项**:
  - 基础: image_file（必需）
  - 可选: format/png/jpeg/webp, channels/rgba, bg_color/#ffffff, size/preview, crop/true
- **常用场景**:
  - 1688产品图去背景（透明PNG或白底JPEG）
  - 小红书图片优化（preview尺寸+crop裁剪，更快更少积分）
  - 批量处理脚本（Python SDK遍历目录）
- **账户信息**: 计划（Free/Pro/Enterprise）+ maxCredits + usedCredits
- **调研报告**: intel/Public-APIs-Poof-背景移除API调研.md（4.4KB）
- **下一步**: 需官家注册账号（https://dash.poof.bg）获取API Key
