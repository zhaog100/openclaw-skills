### Public-APIs-ShotOG API调研 ⭐⭐⭐⭐⭐
- **API信息**: ShotOG - Open Source OG Image Generation（MIT开源）
- **核心功能**: Open Graph图片生成，社交媒体分享封面
- **运行环境**: Cloudflare Workers（边缘计算，~17ms冷启动）
- **模板数量**: 8个（basic/blog/product/social/event/changelog/testimonial/announcement）
- **批量支持**: 最多20张/请求，并行渲染，配额预检查
- **输出格式**: PNG（默认）或SVG
- **API端点**: https://shotog.2214962083.workers.dev/v1/og
- **定价**:
  - Free: 10/天 或 500/月，10/分钟
  - Starter: $9/月，5000/月，120/分钟
  - Pro: $29/月，25000/月，300/分钟
  - Scale: $79/月，100000/月，600/分钟
- **集成场景**:
  - 闲鱼商品分享卡片（product模板，title+subtitle+logo）
  - 小红书笔记封面（blog模板，9:16竖版，1080x1920）
  - 产品发布公告（announcement模板）
  - 批量生成封面（20张/请求）
- **SDK**: npm install shotog，支持JavaScript/TypeScript

### Public-APIs-Poof API调研 ⭐⭐⭐⭐⭐
- **API信息**: Poof - Background Removal API（https://poof.bg/）
- **核心功能**: AI驱动背景移除，支持PNG/JPEG/WebP，像素级精准度
- **集成方式**: REST API + Python SDK + TypeScript SDK
- **API端点**: https://api.poof.bg/v1/remove
- **认证方式**: Header x-api-key（以poof_开头）
- **参数选项**:
  - 基础: image_file（必需）
  - 可选: format/png/jpeg/webp, channels/rgba, bg_color/#ffffff, size/preview, crop/true
- **常用场景**:
  - 1688产品图去背景（透明PNG或白底JPEG）
  - 小红书图片优化（preview尺寸+crop裁剪，更快更少积分）
  - 批量处理脚本（Python SDK遍历目录）
- **账户信息**: 计划（Free/Pro/Enterprise）+ maxCredits + usedCredits
- **调研报告**: intel/Public-APIs-Poof-背景移除API调研.md（4.4KB）
- **下一步**: 需官家注册账号（https://dash.poof.bg）获取API Key
