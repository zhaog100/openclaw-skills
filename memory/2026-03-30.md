## 📚 晚间学到的经验

### 10. 青龙面板部署流程 ⭐⭐⭐⭐⭐
- **Docker 安装**: `apt install docker.io`
- **青龙容器**: `docker run -d --name qinglong -p 5700:5700 whyour/qinglong:latest`
- **脚本库**: clone 到 `/ql/data/repo/` 目录
- **依赖安装**: `npm install axios dotenv crypto-js tslib moment tough-cookie json5 got@11`
- **Cookie 配置**: 通过 API `POST /api/envs` 添加 JD_COOKIE
- **定时任务**: 通过 API `POST /api/crons` 添加任务

### 11. 青龙 API 使用经验 ⭐⭐⭐⭐
- **登录**: `POST /api/user/login` → 获取 token
- **添加环境变量**: `POST /api/envs` body: `{"name":"JD_COOKIE","value":"...","remarks":"..."}`
- **添加定时任务**: `POST /api/crons` body: `{"name":"任务名","command":"task /path/to/script.js","schedule":"cron表达式"}`
- **运行任务**: `PUT /api/crons/run` body: `[taskId1, taskId2, ...]`
- **查看日志**: `GET /api/crons/{id}/log`

### 12. 脚本路径检查 ⭐⭐⭐⭐
- **教训**: faker2 仓库的脚本名可能与预期不同
- **检查方法**: `docker exec qinglong ls /ql/data/repo/faker2/ | grep jd_`
- **常见差异**: `jd_bean_sign.js` → `jd_beanSign.js`，`jd_fruit.js` → `jd_fruit_new.js`

## 📚 系统优化经验

### 13. Linux 内存优化 ⭐⭐⭐⭐
- **Swappiness**: 默认60，建议调到10减少swap使用
- **调整命令**: `echo 10 > /proc/sys/vm/swappiness`
- **持久化**: `echo "vm.swappiness = 10" >> /etc/sysctl.conf`
- **清理缓存**: `sync && echo 3 > /proc/sys/vm/drop_caches`
- **效果**: 释放 ~500MB 内存，系统响应更快

### 14. 内存紧张排查 ⭐⭐⭐⭐
- **检查内存**: `free -h`
- **查看进程**: `ps aux --sort=-%mem | head -15`
- **Docker统计**: `docker stats --no-stream`
- **常见问题**: 2GB内存运行Gateway+青龙+Docker偏紧张
- **长期方案**: 升级到4GB内存
