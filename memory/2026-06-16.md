## 京东脚本替换问题最终解决（2026-06-17 凌晨）

### 根因
- 6dylan6/jdpro 的 JS 脚本是**混淆压缩**的，只有 5-11 行但每行数万字符（100KB+）
- 之前误以为"只有 5 行 = 空壳脚本"，实际上空壳只有几百字节（776B-1.1KB），真实脚本 115KB+
- 容器内文件系统支持大文件写入（JDSignValidator.js 2079行/84KB 一直存在）
- curl/docker cp/tar 方式下载到容器内时内容被截断，但 Node.js 的 writeFileSync 可以完整写入

### 解决方案
- 用 `docker exec qinglong node -e "..."` 在容器内通过 Node.js 从 GitHub HTTPS 下载并写入
- 关键代码：`https.get()` 获取内容 → `fs.writeFileSync()` 写入容器内文件

### 替换结果（全部 MD5 验证一致）
| 脚本 | 大小 | 对应 |
|------|------|------|
| jd_bean_extra_sign.js | 115K | 打卡领豆 |
| jd_wangwang_manor.js | 169K | 汪汪庄园 |
| jd_farm_auto_tasks.js | 260K | 京东农场 |
| jd_farm_lucky_wheel.js | 139K | 农场幸运转盘 |
| jd_gift_card_beans.js | 130K | 礼品卡领豆 |

### 系统 crontab 恢复
- 京东任务之前从系统 crontab 中消失（6月13日 13:46 最后修改时丢失）
- 已恢复 7 个京东 cron 任务（签到/额外签到/庄园/农场/转盘/礼品卡/评价）
- 系统 crontab 当前共 19 个任务（7京东 + 4公考 + 1国企 + 1热点 + 1复盘 + 2周任务 + 3石油黄金）

### 教训
- **混淆 JS ≠ 空壳脚本**：6dylan6/jdpro 的脚本就是 5 行但 100KB+，这是正常的
- **Node.js writeFileSync 可以绕过容器写入限制**：curl/docker cp/tar 都不行，Node.js HTTPS 可以
- **永远用 MD5 校验文件完整性**：不要凭行数判断文件是否完整
