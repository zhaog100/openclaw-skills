## 🎓 今日学习要点

### 1. Git 安全
- **GitHub Push Protection** 自动检测 token 泄露
- **历史提交** 中的 token 也需要清理
- **BFG Repo-Cleaner** 可以清理历史中的 secret

### 2. 远程仓库管理
- **技能仓库** vs **个人信息仓库** 分离管理
- **默认分支** 不能直接删除
- **强制推送** 也无法绕过 Push Protection

### 3. Token 管理
- **定期轮换**: 建议 90 天更新一次
- **权限最小化**: 只授予必要的权限
- **脱敏规则**: 只显示后 4 位 (`ghp_***...4I6`)
