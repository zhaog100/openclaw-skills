1. **Sequelize DATE 类型期望字符串时间戳** — 整数会导致 `date.includes is not a function`
2. **青龙 2.21.0 架构变更** — gRPC worker 内置到 app.js，不再有5500独立端口
3. **青龙 2.21.0 PM2 单进程模式** — 配置文件从 apps[4] 变为 apps[1]
4. **sharp 在 Alpine 容器** — 需要 musl 版（sharp-linuxmusl-x64.node），不能直接用 glibc 版
5. **Cookie 格式** — `pt_key=xxx;pt_pin=yyy;`（分号后不要空格，否则 HTTP header 非法）
