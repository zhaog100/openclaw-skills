- **影响**: 用错地址 → key 401 → 所有百炼模型 model_not_found → fallback 到智谱

### OpenClaw Model Failover 机制 ⭐⭐⭐⭐⭐
- **来源**: 官方文档 docs.openclaw.ai/concepts/model-failover
- **流程**: primary 失败 → auth profile rotation → fallback 链逐个尝试 → 成功后写入 session override
- **Session override**: fallback 成功后自动写入 modelOverride/providerOverride，锁定会话模型
- **改模型不只是改配置**: 要同时清理 session override + cron model + auth-state cooldown
- **models.providers 配置**: 需要同时设 baseUrl 和 models 数组，否则 config invalid
