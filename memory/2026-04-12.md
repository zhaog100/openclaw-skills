## 今日经验教训

### 飞书文件传输限制 ⭐⭐⭐
- 飞书 Bot 不支持直接发送文件附件
- 代码块内容在飞书中难以复制（格式丢失）
- 替代方案：推送到 GitHub → Raw链接下载；或创建飞书云文档
- 飞书云文档需要 Bot 有文件夹权限（需官家先创建并共享）

### QQ Bot 多账号配置 ⭐⭐⭐⭐
- 从单对象改为数组格式支持多Bot
- 每个Bot独立 appId + appSecret
- 修改后需重启 Gateway

### 金融数据API调研 ⭐⭐⭐
- yfinance: 免费、无需Key、Yahoo Finance数据，适合快速原型
- Alpha Vantage: 免费额度25次/天，有官方MCP Server，适合生产
- akshare: 国内免费、无需翻墙、数据稳定，推荐作为主数据源
- 分析石油黄金相关性时用收益率(pct_change)而非绝对价格，避免量级差异

### yfinance限速问题 ⭐⭐⭐⭐
- 腾讯云/阿里云IP段容易被yfinance封禁（Too Many Requests）
- 封禁可持续数小时甚至更久
- 周末（市场休市）限速更严格
- 解决方案：akshare作为主数据源，yfinance备用

### 磁盘清理经验 ⭐⭐⭐
- pip缓存(/root/.cache/pip/)和npm缓存(/root/.npm/)是最大的空间占用
- journal日志可用 --vacuum-size=100M 限制
- 定期清理：pip cache purge + npm cache clean --force + apt clean
- 2G内存VPS建议保持磁盘使用<50%
