## 📚 今日经验教训

1. **submodule 规则**：openclaw-skills 是子模块，git pull 前要 git stash 避免冲突
2. **docker-compose volumes**：挂载路径不对会覆盖镜像文件导致无法启动
3. **npm vs pnpm**：在 OpenClaw 容器里 npm 反复 ENOTEMPTY，pnpm 一次成功
4. **Gemini embedding**：免费层配额有限（429 RESOURCE_EXHAUSTED），需等重置
5. **身份确认**：启动时既要多文件交叉验证记忆，也要根据主人反馈快速修正
6. **青龙 cron 任务**：不要建过多任务，9个核心任务足够覆盖京东薅羊毛
7. **多通道记忆**：用 multi-channel-memory 脚本提取对话，保存到 memory/chat-YYYY-MM-DD.md
