## 一、🔥 正在进行：2026年四川省公务员补充录用（1,702人）

### 报考条件

| 条件项 | 具体要求 |
|--------|----------|
| 报名资格 | 已参加2026年"四级联考"、全省政法系统公招、基层选调生招考、全省公安机关特警专业人才等项目笔试 |
| 排除情形 | 考录过程中有违规违纪、笔试/心理素质测试有缺考或零分科目者除外 |
| 已被录用 | 已被中央机关或其他省（区、市）确定为拟录用人员的，不得报名 |
| 笔试类别 | 笔试考试类别与拟报考职位相同，考试科目≥拟报考职位科目 |

### 报名程序

| 项目 | 内容 |
|------|------|
| 报名时间 | **2026年6月8日9:00至10日18:00** |
| 报名方式 | 登录"补录专题网站"（scpta.com.cn），用身份证号登录，选1个职位报名 |
| 修改机会 | 报名截止前可修改2次 |
| 报名公告 | [查看原文](https://www.eoffcn.com/kszx/detail/2105269.html) |
| 职位表 | [补充录用职位表（附件1）](https://www.scpta.com.cn/front/News/info/add46e5e5cb8426a9e833a4e718636ba?t=56) |
| 报考指南 | [补充录用报考指南（附件2）](https://www.scpta.com.cn/front/News/info/add46e5e5cb8426a9e833a4e718636ba?t=56) |

### 考试安排

| 环节 | 时间 | 说明 |
|------|------|------|
| 资格初审 | 6月12日-15日24:00 | 按笔试成绩从高到低，按比例初审 |
| 初审结果查询 | 6月16日-17日18:00 | 登录补录专题网站查询 |
| 加分确认 | 6月11日16:00前 | 将加分证明材料送交市(州)党委组织部或省级招录机关 |
| 民族语言测试 | 另行通知 | 仅阿坝州部分职位，不合格者不得进入下一环节 |
| 面试 | 6月下旬（暂定） | 满分100分，成绩占比见职位表 |
| 体能测评 | 另行通知 | 交通运输、法检司法警察、公安人民警察、监狱人民警察职位 |

### 成绩计算

| 类别 | 计算公式 |
|------|----------|
| 普通岗位(笔试:面试=6:4) | 笔试=行测×30%+申论×30%+加分 |
| 普通岗位(笔试:面试=5:5) | 笔试=行测×25%+申论×25%+加分 |
| 公安执法勤务类 | 笔试=行测×24%+申论×18%+专业科目×18%+加分 |

### 体检要求
- 按《公务员录用体检通用标准（试行）》执行
- 人民警察/司法警察职位另按《公务员录用体检特殊标准（试行）》执行
- 通用标准：矫正视力不低于4.8，无慢性病、传染病等

⚠️ **今天是报名第一天！报名6月10日18:00截止，符合条件者尽快报名！**

## 三、📝 四川省公务员通用报考条件

| 条件项 | 要求 |
|--------|------|
| 国籍 | 中华人民共和国国籍 |
| 年龄 | 18-35周岁（2026年高校应届毕业生可放宽） |
| 学历 | 大专及以上（不同岗位要求不同，详见职位表） |
| 学位 | 部分岗位要求学士及以上学位 |
| 专业 | 详见各职位表要求 |
| 政治面貌 | 部分岗位要求中共党员 |
| 基层工作经历 | 部分岗位要求的2年以上基层工作经历 |
| 身体条件 | 符合公务员录用体检标准 |
